## 1. 多题并行设计 v2(数据驱动,本夜 T1 census 输出)

**核心转向:规模单位从"题"换成"病理"。** M26b 44 道摇摆题机械聚类
(pathology_census.py,fail 侧墙标记率 / pass 侧泄漏标记率 / 死法混合 / Bash 流):

| 病理簇 | n | 判据 | 药系(已有原型) | 处置 |
|---|---|---|---|---|
| leak-route | 12 (27%) | ≥半数 pass 摸基准工件 | **无** | **隔离仓**:出清诊疗队列,归床修复(#31) |
| wall 墙死 | 13 (30%) | ≥半数 fail 带 403/503/人机验证 | C-R1-03 系(fetch 重试+镜像转向) | 可治,最大簇 |
| wrong-close 误收束 | 16 (36%) | done 答错主导,无墙无泄漏 | C-R1-02 系(verify-first 提交门) | 可治 |
| friction 摩擦 | 2 | Bash 空载荷流 | 851e 系已探 | 可治,小 |
| starved 步饥饿 | 1 | budget 主导 | 步帽在环外 | 挂账 |

- **"发散族"解散**:WS 狂喷题全落 leak-route——发散是"诚实路线不存在"的症状,不是病理。
- **一簇一药 + 触发门控 = 干扰控制**:药只在自己病理签名上开火(steer 谓词/工具失败路径/
  提交门),44 题不需要 44 药,需要 ~4 药。
- **组合槽位现实**(接缝审计):prompt 桶=单例(template_path 整体替换,**prompt 药不可组合**,
  须归并为单一演化模板内的分节);tool 桶=同名单例(异名可组合);processor 桶=列表可组合但
  需 steer 仲裁(runtime_policy 首中即返;多处理器 append 会叠字)。
- **验证经济学**:逐病理代表题成对试验(~$30/簇)而非逐题(~$250/轮);held-out 簇友=迁移证据。
- **喂食带宽**:一次 clinic 会话 3-5 份代表档案(Evolver K≈3-5 上限,161 步/$26 实测);
  多病理=多会话,不是一次全喂。
- **活战役孪生取材**:live 纪元可能无 pass(所以才失败)→ clinic 轮对队列题跑 k=2 现造同纪元
  孪生(只对队列题双倍 rollout)。
