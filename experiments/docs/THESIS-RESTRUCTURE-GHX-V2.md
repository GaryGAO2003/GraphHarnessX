## 2. 实验 = 阶梯（as-built）

| 级 | 旗标 | 语义 | 旧臂映射 |
|---|---|---|---|
| L0 | 无 | 官方 AEGIS 原样 | — |
| L1 | UNFOLD + IDENTITY | 只记录不干预；**兼任基线与原论文 Global 臂首次独立复现** | A |
| L2(=L3) | + AEGIS_EVIDENCE | 因果锥+facts 进四角色工作区（G1b 指针注入=必见）；L2/L3 现共用一开关 | B |
| L4 | + GRAPH_GATE | 第六道门：候选牵连组件在失败任务执行图里数得到吗；现阶段无真任务 replay U 时诚实放行（checked=False） | V− 正向 |
| L5 | 候选面=类型化图编辑（渲染回官方格式，下游五门/Critic 原样跑） | **主系统 / headline 臂**：首个改官方 prompt 内容的级（登记偏离）；直接消灭 §3.3 解析死亡 | **主对照 = L5 vs L0** |

- **两张桌子**（CH4 骨架）：L2 给**诊断桌**（Digester/Planner）上图——治「病因找不准」；
  L4 给**审批桌**（五门+Critic）上图——治「死改动被误采纳」。
- **两类增益分开讲**（措辞铁律 v2）：L2 是**表征变换**（串行叙事→预计算因果结构，
  固定预算内可用信息密度上升；注入字节数为负增长，防「你只是喂得多」）；
  L4 改的是**验证难度**（文本可以吹牛，节点计数不能），与信息量无关。
- **床/轮/种子**：GAIA text-only 103 题；**轮数口径未冻结**（正文一律参数化写
  R 轮 + 指偏差表；在飞战役为 10 轮，原文协议 15×3 种子，降档已进偏差表）；
  1 种子；pass@1；判分=加固判分器（正式跑统一口径）。
- **预注册 endpoint**：peak−final 非退化（同谱系配对量），分支预写死——
  L1 复现踏车 ⇒ L2 非退化即分数级证据；L1 平走 ⇒ 分数侧只主张非劣，
  重心落过程指标。±5 题单轮噪声规则。降档纪律（⑤后新序）：**L0+L5 headline
  与在飞 L2 不可降 > L4 先降**；L5 若赶不上窗口，预声明 fallback = 消融梯
  （L0/L2/L4）作实证主体 + L5 交机制与 commissioning 证据。
- **对称纪律**：两臂同机同钥同工具字节；serper 后端两臂同换（config hash
  同变即配对有效）；反污染两闸两臂恒开（对照中自消，进偏差表）。
