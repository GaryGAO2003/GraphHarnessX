## 1. 新 RQ 与贡献

**RQ1（诊断）**：文本/YAML 提交面的自演化环在实测中把预算烧在哪里？
（非法/无效候选、门打在噪声上、有效池 = min(K, 簇数)。）

**RQ2（机制）**：harness 组合层能否表示为类型化图 IR，使候选在评测前被
build 时验证拦截（DFA 生命周期 × 引证门 × 事务化 GraphEdit，fail-closed）？

**RQ3（对照）**：同一进化环、同任务床、同 proposer 预算下，类型化图编辑面
相比文本面是否提高单位预算产出（合法率 / 有效率 / 首个存活改进 / 留出回归率），
且端到端 pass@k 非劣？

**贡献**：
1. AEGIS 复现与诊断：变体池（K=8）病理量化（数据已在手）+ **Global 臂
   （K=1）首次有界独立复现**（由 P5 A 臂兼任——原论文 headline 无公开
   实现、从未被独立验证，官方 repo 唯一存在的正是单变体形态）；
2. GHX：组合层图 IR（三层 hash、声明层 + 引证门、Δ8 DFA、P3 事务验证器）——
   08-07 判定「IR + 验证 + 图编辑」三合一位置无单篇占据；
3. 表示轴对照实验（RQ3）+ 验证器历史语料回放（零 API 保底读数）；
4. 先占点名与分界：MermaidFlow / AgentFlow / HarnessForge / NLAH /
   2607.13683（门-噪声）/ 固定图调参线（DSPy/TextGrad/GBC）。

**不再主张的**：分工优于随机分工（旧 B2−B1）、池修复（能力簇 + ε）、
多 vs 一任何形态。SA-matched 生死线随之退役（§4）。

**Claim 措辞铁律（防 efficiency-hack 误读）**：图化的主张不是「更省预算」，
是**换信号**——文本面进化环唯一反馈是事后的、统计的、被 4.6pp 噪声地板
压着的分数差；图 IR 把三类问题换到确定性通道：**对错**（统计分数 →
确定性 witness，族1：SIGIL/Agentproof/MermaidFlow，NLAH 附录 G 反面自证）、
**波及**（无界文本 diff → 可达性有界，族2：SE 切片/选测/Nix，
MermaidFlow 无增量重验是差异化点）、**身份**（候选相等不可判 → 规范化
哈希可判，族3：去重/lineage/跳测/多样性度量）。单位预算产出只是三条
性质在读数上的投影；endpoint 倒置因此不是退而求其次——过程指标直接测
信号质量。语料另两族 graph 优势（**归因**：GraphGPO/GBC/Tarantula/GS-D；
**结构化检索**：HippoRAG/GoS/KG-A2C）属推迟的 GS 侧，CH7 必须自答
「为何只取组合层」——two-graphs-one-trace 愿景，宏观层本文立住、微观层
已设计待跑。CH4 题眼可引 SIGIL："the graph, not the model, carries the
procedure"。

**Endpoint 倒置（预注册）**：主读数 = P5 九项过程指标（parse 率、S0–S4 通过率、
roundtrip 率、build/smoke 率、genotype 多样性、每评测/每 token 回报、
首个可接受改进时间、留出回归率、选择性重测节省）；**pass@k 只设非劣界**。
锚点纪律：AFlow ~50% / MermaidFlow >90% 分母不同，只可定性引。

**分数侧预注册细化（防跌不是推涨）**：最有据的分数效应通道是「不接受
回归」——原文 Global 形状是退化（final 49.5 < peak=initial 73.8，
−24.3pp treadmill），witness 拦截 + 显著性门针对的正是这条。故加第二个
分数 endpoint：**B 臂 peak−final 非退化**（同谱系配对量，比终值差好检测），
并预写死条件分支：(i) 若 A 臂复现 treadmill 形状 ⇒ B 的非退化即分数级
证据；(ii) 若 A 臂在本档位平走 ⇒ 分数侧退回非劣，主张全落过程指标。
**不得预设 A 必退化**（我方 K=8 数据无偏计分后 peak−final=0，且那是池
非 Global——方向性假设而已）。「B 终值显著高于 A」不承诺：功效（噪声
地板 4.57–6.41pp vs 15–20 题子集）与搜索空间上限（Initial 73.8 已高）
两头压着。效率→分数的次要通道（省下预算换更多有效轮次）经 reward per
evaluation/token 报告，落机制归因层，不进 headline。

**统计口径**（沿用已预注册项）：同题配对（McNemar / 配对 bootstrap 95% CI）；
接受门 = 显著性门（04 号：超噪声带才换冠军；点名 2607.13683 先占并写差异）；
peak 去偏 + 07 号 fork 修正；infra 失败单列；元 agent token 与评测 token 分账，
全成本报告（calls + $ + 墙钟，2606.13003 纪律）。

**臂纪律**：两臂动作作用域同构（都限组合层）；validator witness 声明为表示
处理的一部分（IR 使机器可核反馈成为可能——这就是论文主张），A 臂保留其自然
错误信号（build 异常栈）；archive/Pareto/island 任何单边加入即污染表示轴。
