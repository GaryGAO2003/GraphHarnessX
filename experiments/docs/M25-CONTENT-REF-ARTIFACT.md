# 证据面伪影：content_ref 外置 —— 全战役最大翻案（08-23）

> 修复 = `03d4b42`（flatten 缝还原）。本文 = 取证 + 修正后的机制史 + 对既有结论的逐条重估。

## 1. 伪影是什么

日志（`harnessx/tracing/journal.py`）为控制 JSONL 行大小，把 >2048 字节的工具结果外置到
`<session>/tool_results/*.txt`，行内记 `content:"" + meta.content_ref`。这是**录制编码**，
不是交付语义——活体消息里模型拿到的是全文。

但 `_flatten_sessions_to_raw` 原样 copy session JSONL 进 `R{n}/raw/`，vendored 的
`clean_trajectory` 再抄进 `trajectories/`。**Digester、Layer A、图投影、motif 库全部读这份
拷贝**——对它们而言，每个大号成功载荷都是"空"。

## 4. 三条结论（论文级）

1. **药是真的：empty_consumed 真值 37 → 4，9 倍坍缩。** 分数唯一可见的跳变（R0→R1 +17）
   正落在第一次坍缩上（37→19，SilentEmptyGuard 上车）。empty-guard 药族不是打幻影——
   它治好了真病。
2. **仪器谎报，环空转**：记录面五批纹丝不动（~30，被伪影常数托底），环因此持续向同一
   方向堆药；R13 Planner 甚至把伪影本身命名为头号主题（"pointer-only 交付，24 题"——
   全部是被外置的行）。**"环治好了它看不见的病，仪表却说没治好。"**
3. **残余失败换了物种**：R0 无 motif 失败 7/48 → R12 **24/33**。机制性失败已清光，剩下的是
   "内容取了、读了、照样答错"的方向/方法失败——与摇摆层配对分析（失败轮步数 +4.5、
   工具 +0.45，47/56 失败轮更长）互相咬合。**这是下一战役的靶。**
