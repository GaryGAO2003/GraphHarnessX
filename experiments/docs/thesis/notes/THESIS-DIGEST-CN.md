## 一句话

**这台自演化 harness 会看、会分类、会开药、会自己造工具、还会该弃权时弃权——但它听不见自己有没有治好。**
论文做的事：证明它的证据是假的 → 换成图原生的真证据 → 发现结果两个方向都没分开 → 找到缺失的那个器官（"这次编辑起效了吗"），而全领域没有一个系统在测它。

**图没让这个环变聪明。图让这个环变得可核查。**

## 摘要

LLM agent = 模型 + harness，有一整片文献在自动演化 harness。**HarnessX/AEGIS 是唯一一个代码公开的 harness 级闭环，而且是治理得很仔细的一个**：四个元角色读每一条轨迹（成功的也读），每个候选编辑都要过五道确定性闸门——其中有一道**结构门**强制 12 条证据不变量、一道**新颖门**对着已驳回签名账本去重、一道**反事实门**把提议的 processor 链回放在上一轮通过任务上、任何变化即拒。**这比它任何一个邻居的治理都多。**

我们把它逐字节 vendor、大规模跑起来——据我们所知是首次独立执行：6 个战役各 16 轮，96 轮、8,393 次新鲜评测，100 题纯文本 GAIA 床。**跑起来暴露的不是一个缺陷，是一族。** 中枢证据信号判定"工具输出被用了"的条件是下一条 assistant 消息逐字重复 ≥20 字符，而这张床的答案中位长度是 9；这一列按构造就瞎，把否定判决打在 **75.0%** 携带答案的调用上，抵达 **86%** 的档案，候选踩着它上车。它周围，**四条反馈通道写了但从未送达**，论文规定的棘轮没有实现，而环通过自由文本编辑自己——**没有任何东西能确认候选文档和实际落地的改动是同一次干预**。

作为回应造了 **GraphHarnessX（GHX）**：类型化可执行组合图、每次调用展开的执行 DAG（边是观测的不是重建的）、其上的因果锥、一道回放门和一道**第六接纳门**把候选的主张对着记录的执行核、三层嵌套哈希把"提议的 / 部署的 / 跑了的"分开、类型化事务性候选面。它从外部挂在未修改的底座上，所有旗标默认关。**它买到的是可核查性**：假列在图臂 859 份档案里 0 份、摘要引用锚点翻倍且失败率降到七分之一、畸形候选死亡砍半、**18 个已过全部五道官方门的候选被抓到在点名一个从不存在的节点**。

假设 H1——忠实的执行级证据会改善编辑定位和结果——作为预先设定的假设，在替代终点上**未获支持**，因为原定终点被证明不可测；**那正是本文的结果**。同配置重测在三个种子上翻转 **21.0 / 20.1 / 19.2%** 的任务结果，≤5 题的总分 delta 不携带信息。考古显示未修改的环早在四个战役前就从单次观察和假证据里正确开出同样的处方：**开处方从来不是瓶颈**。一个阳性对照标定仪器——分数轴捡回唯一已知起效的干预，只因它的效应是这个环实际产出的三倍——而两次全战役扫描表明跳出噪声带对"编辑起效"**既不必要也不充分**。分数轴不是机制幅度的单调换能器，它的零意思是"低于阈值，或高于阈值但指错方向"——包括我们自己的。

命题：**自演化 = 变异 + 选择 + 读数**，选择低于地板时累积增益无论变异质量都非正。给它一副数量遗传学的骨架，掂量对立解释，提出四级读数阶梯——所有被调查的系统都在第 0 级接纳候选。GHX 里 0–2 级活着；第 3 级——这次编辑改变结果了吗——本文手工做过，它是领域缺的那个器官。

**图没让环变聪明。图让环变得可核查。**

## 第 1 章 · 引言

### 1.1 被研究的系统

agent = 模型 + harness，harness 常是主导杠杆，于是有了一整片自演化 agent 文献。多数演化 prompt / workflow / agent 代码；**极少数在 harness 层闭环**。HarnessX/AEGIS 是其中之一，也是本文的对象。

**它的环六阶段**：solver 在固定配置下攻床 → **Digester** 读每条轨迹（失败和成功都读；成功模板要它"别庆祝"，去点名可复用策略和潜在脆弱性）写逐任务档案 → **Planner** 合成一份 landscape → **Evolver** 写零个或多个候选（manifest + 应用后的配置），改配置 / 工具 / prompt / processor → **Critic** 逐个审、可以质询 Evolver、并把候选当集合对着 scoreboard 审 → 幸存者过**五道确定性闸门**（便宜的先跑）：**结构门**（12 条证据不变量：每个引用锚必须在盘上存在且指向轨迹内部）、**新颖门**（对已驳回签名账本去重）、规范化、**反事实门**（把提议的 processor 链回放在上一轮通过任务的记录事件上，输出或退出原因有任何变化即拒）、合成任务回放。每个角色都在读写作用域门后面（不许读 harness 源码、不许读别的 run）。环按可行动性分数**选择性地**调用自己；上车的候选**事后按它自己预测要翻的任务打分**。

> 这比第 2 章任何邻居的治理都多——这正是选它的原因：**一个守得这么严的环，才是问"这些守卫看得见什么、看不见什么"的合适对象。**

**复现时撞到了什么**：论文的 GAIA 头条是集成提升 0.0 → +13.6%。头条依赖的**变体池和集成路由不在放出的代码里**——release 是单一血统、`ship | no_op` 二选一。GAIA runner **默认只跑一题**、没有启动脚本、没有提交任何数字；作者自述的 14 轮 GAIA-64 试跑，结果目录被 `.gitignore` 排除。仓库里唯一完整的实验在另一个 benchmark 上 (F19)。另有三条论文规定代码里没有：**全局棘轮**（已解题不得交还）、保留的 **±5% 噪声阈值**、**每格三个种子**。

> **所以：有一个数字，没有一个可重算的数字。** 我们跑的是 released system，不是论文描述的 system；每一处分歧记在附录 A。

### 1.2 跑了什么，以及为什么是这张床

系统在 sha256 manifest 下逐字节 vendor，由测试强制。6 个可作证战役，全部在 GAIA 纯文本切分的 **100 题无图像床**上读——全文每一个数字只用这一张床。每个战役按正式 16 轮窗读，**96 轮、8,393 次新鲜评测**进入证据基。

**为什么 GAIA，为什么这 100 题**——四条理由，按分量排：

1. **它是作者自己的床。** 论文头条是 GAIA 数字、自述里有 GAIA 试跑，所以只有在 GAIA 上 released system 才能被拿去对论文。
2. **纯文本切分让 solver 留在记录器能归因的范围里。** 纯文本题靠 harness 自己的工具（shell、读文件、网络搜索）作答，每一步都是执行图能记录的事件。切分里 103 题有 3 题带图像内容、记录器无法归因，剔除后 100。
3. **有 room。** 六战役里曾解出过的题并集 **97/100**，任何臂记录过的最好单轮 **76**——**21 题的余量**，而且 47 题"有时过、不稳定" (F16)。床既不饱和也不贴地，harness 效应有地方显形。
4. **小到每轮能整床重跑。** 100 题一个战役能完整跑 16 遍，**同配置重测——第 5 章整个仪器——才付得起。**
### 1.3 跑基线暴露了什么

环的中枢证据信号——一次工具调用的输出是否**被用了**——是**结构性失明**的，而失明来自它自己的构造。

这一列判定的方式：**紧接着的下一条** assistant 消息与工具输出是否共享 **≥20 字符**的逐字子串。GAIA 最终答案**中位长度 9 字符，90 分位 14** (F3)。一个短事实无论怎么被使用，都过不了这个地板。

两个后果不需要任何实验就成立，因为第一个是代码的性质、第二个是 benchmark 的性质。它把否定判决打在**携带答案的调用**上的比率是 **75.0%**（559 次这类调用中的 419 次）(F2)。

这个判决不是惰性的：它抵达 **86.0%** 的档案 (F4)，被逐字引用进候选文档 (F5)，**有一个候选踩着它上车了** (F6)。

基线的其余部分全在踏车：平台期一条平线、一本"修好一个弄坏一个"的编辑账、以及全部落在同配置重测包络内的上车边际。

> **H1.** 环的失败是一个**证据**问题：忠实的执行级因果证据会改善编辑定位和结果。

### 1.4 假设与它的文献位置

四条独立的文献路线都把需要的那个位置留空了。自演化论文改进候选**生成**，然后按聚合分选择。归因方法是离线的，在自己的 benchmark 上报 **14.2%** 到大约 **11%** 的定位准确率。执行溯源服务于人类审计——2026 年的一篇综述明确指出，截至其 cutoff，**没有工作把它闭合进改进环**。类型化候选空间在合法性上赢过自由代码，但类型化的是**可以被提议什么**，从不是**实际发生了什么**。

H1 在图战役之前作为可证伪命题注册，针对**编辑定位**。它**在声明的替代终点上被否决**：注册的终点在这个设计上被证明不可测，而这件事本身就是主结果。

三个问题都有了定论：
- **Q1 诊断**：证据是假的，瞄准没有可测增益，保留受噪声约束。
- **Q2 非干扰**：是——记录器对环的决策输入是只写的，seam 在退出时恢复，有同窗配对演示支撑。
- **Q3 图证据的效应**：不可检测，而在注册终点上根本不可测。

### 1.5 实验判决（只给头条）

- **造出来了、在工作**：假信号从每一份图臂档案里消失 (F7)；图闸门有活体触发记录 (F11)；环自己开始用图了 (F38)(F20)。
- **结果两个方向都没分开**。编辑定位**在这个设计上不可测**——两臂的候选集在不同闸门制度下被接纳，且抽自相差 9 个百分点的底池，这是**一次缺席的测量，不是一个功效不足的零结果** (F9c)(F9d)。分数同样没分开：共同床上臂均平台期差 **+2.7** 题，对着 **−8…+5** 的同配置摆幅 (F46)；战役内斜率差达 **p = 0.10**，而设计地板是 **0.05** (F47)。**这是对称的，不是非劣性主张**——没有注册任何 margin。
- **一个过程指标下降了，机制被点名**：上车率 **0.62/轮 对 0.88** (F10)，因为图臂多跑一道第六闸门，它杀掉了 **18** 个已经通过全部五道官方闸门的候选——同时候选**死于畸形**的比例砍半 (F53)。**更少的候选，更高的合法性，多一道闸门。**
- **候选面换了形状，不是换了触及范围**。提案变成类型化图编辑，原子提交，产物机器生成；环通过图喂的通道自己写出了一条运行时规则并通过了离线回放闸门 (F20)(F38)。**官方自由文本路径本来就能装一个 processor，而且确实装了** (F39)。
- **一次预先设定的配对疗效试验返回零**，机制终点持平而治疗确实在起作用 (F34)。

**H1 被否决，在声明的替代终点上。** 原定终点连同它自己的可测性一起死了，一个这样的终点不能承载证伪，所以否决落在三个**没有预先设定**的终点上——在这里点名而不是悄悄换掉：考古 (F38，最强且独立于任何 lift 数字)、预先设定的疗效试验返回零 (F34)、结果轴不分离 (F14)(F46)。

**替换是被测量逼出来的，不是看到方向之后挑的——而不可测性本身就是本文的结果，不是它的意外。**

### 1.6 更深的发现：缺失的读数

**开处方从来不是瓶颈**：喂了证据的环"发现"的药系，官方环早在零图臂、假证据、单次观察下、四个战役前就正确开过了 (F38)。每个药系后来都不继承地重现——**重开处方踏车**。图改变的是证据**制度**（卡片在所有执行图上回放规则、带触发数和假阳数上车），论证质量爬到第 2 级；**第 2 级仍不是第 3 级：触发点是死亡签名，不是治愈点。**

**阳性对照标定了什么**：唯一一次机制上已知起效的干预——饿死修复把预算耗尽退出从 **35 塌到 4**、分数 **+9**、跳出同配置带——被保留了整场战役（棘轮的存在性证明），然后**没到任何后续战役**：目标是指向自己战役目录的路径，后面的种子从干净模板生成，**继承通道不存在** (F39)。临床上这叫 assay sensitivity，靠捡回一个已知有效的干预来证明。分数轴确实捡回了它——**但只因为它的效应是这个环实际产出的三倍**（|δ| ≲ 3 对 −8…+5 的带）。两次全战役扫描说比检测下限更糟：出界移动一半发生在零 ship 的轮次，两次机械尺寸相同的干预分数分别 +9 和 +4 (F48)(F49)。**分数轴不是机制幅度的单调换能器**，它的每个零都意味着"低于阈值，或高于阈值但指错方向"——包括本文自己的。扫描在第 6 章，论证在第 7 章。

**读数命题与阶梯**：**自演化 = 变异 + 选择 + 读数。** 领域的选择信号是聚合分，在这张床上它坐在噪声地板之下（三种子 21.0 / 20.1 / 19.2%），保留退化成漂移。命题讲的是噪声下的效应可检测性，与"瞄着能力墙开药是安慰剂"那个对立解释 (F40) 并列而非凌驾，§7.1 认真掂量它。建设性的对应物是四级阶梯——**L0** 在部署配置里、**L1** 曾执行、**L2** 触发且在什么上、**L3** 触发改变结果了吗。GHX 里 0–2 级活着 (F11)(F38)，第 3 级本文手工做了 (F34)(F36)，**所有被调查的系统都在 L0 接纳候选。**

### 1.7 贡献

- **C1** 官方自演化 harness 的首次独立执行与公开读数 (F19)。
- **C2** 对其证据管线的量化审计：一个**构造性证明**——"输出被用"这一列无法登记短事实的使用；它把该标签打在携带答案调用上的比率；以及该标签伸进决策的深度 (F2–F6)。**全部在无图条件下建立。**
- **C3** GHX：非侵入式集成的图原生运行时，假信号被移除、闸门有活体记录 (F7)(F11)，类型化事务性候选面。**不是更宽的触及范围**——官方 Evolver 本来就能编辑 processor 平面，而本文唯一一次超噪声修复正是那样上车的 (F39)。主张是候选的**合法性与身份** (F20)。
- **C4** 对 H1 的预先设定检验及其在声明替代终点上的否决，连同确立"不可测"的测量方法学：翻转率、分辨率法则、同窗配对试验、停止算术、触发取证、十五条错误登记 (F9c)(F14)(F34)(F38)。
- **C5** 能力/疗效分离与读数命题：能力链端到端完好 (F36–F38)，疗效通道缺席 (F34)(F39)(F40)，附一个治理红队标本 (F37)。
- **C6** 有根据的路线图：读数优先的自演化（L0–L2 活体 + 手工演示的 L3）、把天花板先定价的床可靠性工程、以及情景笔记通道 (F35)。

### 1.8 口径纪律

比较一律是**臂级**的，不做单因素归因 (F9c)。臂级比较根本不成立的地方（定位——两臂在不同闸门制度下被接纳），两臂分开报告，**不取差值** (F9a)(F9b)(F9c)。

一张床、一个 solver 档位、每臂三个种子 (F44)(F45)；只用审计过的分数。

**数据口径**：早于基线战役的运行（系统尚未正确建成之前的调试期）和两个 GHX 试航战役，**从每一个主张里排除**。证据只落在基线战役、修复后的图战役、两对复现 (F44)(F45)、以及预先设定的探针上。

**三条口径裁定的时点，写出来供读者判断**：

1. 排除试航战役的白名单是 **2026-08-26** 裁的，**在那些战役跑完并被读过之后**。
2. 十六轮读数窗口 **2026-08-27** 固定，以匹配图臂长度；基线的第十七轮**留在脚注里而不是删掉** (F15)。
3. 第三种子的无图臂在**第 7 轮中途**（2026-08-28）被移到 100 题子集上，以使其床可比 (F45)。

**裁定 1 把数字推向了不利于图的方向**：排除试航战役之后，图臂的池化定位 lift 下降了 (F9b)。裁定 2 按构造是方向中性的（它拉平两臂长度）。裁定 3 移除的是床尺寸混淆而不是分数。**没有任何一条裁定是在看到它会朝有利方向改动的那个数字之后做的——而裁定 1 是唯一可核查的那个案例。**

**判断与撤回**：判断型主张标 [C]。维护撤回登记，其中任何一条不再被引用——**包括我们自己早先"这个环开不出因果感知的药"的主张，被我们自己的档案证伪。**

## 第 2 章 · 背景与相关工作

> **章主张**：四条文献路线各自独立地把同一个位置留空——溯源接地的自演化——而四条路线全都按聚合跑分选择，正是本文证明在噪声床上失聪的那个信号。

### 2.1 自演化 agent harness

**自由代码候选空间**：ADAS、Gödel Agent 让 agent 直接改写自己的代码。**Darwin Gödel Machine** 加了一个自修改 agent 的种群档案——本文分层哈希身份最近的先例。Huxley–Gödel Machine 改的是**谁的分数**被聚合，不是信号的**类型**。SICA 在编码 agent 上闭合自改进环。

**工作流演化**：AFlow / A²Flow 演化 agentic workflow，候选表示随时间收敛向类型化图。GEPA 做反思式 prompt 演化。AlphaEvolve 贡献了一串评估闸门——可复用的验证设施，**只是每道闸门验证的都是"分数提升了"**。EvoAgentX 把这些集成成平台。

**最近的问题设定**：**HarnessForge** 瞄的是和本文同一个对象——它把 harness 当作 (Planning, Action, Memory) 文本三元组，用故障归因引导的档案搜索 + 训练策略来演化它，通过接口冒烟测试和 Pareto 适应度验证候选。**同一个问题，相反的路线。** 它没有类型化的构建期验证、没有图哈希身份、没有"候选声明 vs 执行观测"的对账——而且它需要训练，GHX 是免训练、结构性的。**这里点名，而不是留给读者自己发现。**

**2026 年的 harness 级一线**（本文写作那一年长出来的）：**NLAH** 把 harness 从控制器代码抽成运行时解释的自然语言文档，harness token −95%、Live-SWE 上赢过代码 harness——**但它自己的附录承认自然语言"欠规定、跨模型解释不同、被转述削弱"，没有机器可核的约束**。它是本文的**表示层对手**：同一个痛，相反的药，§2.6 正面接。**SIGIL** 反方向走，把散文技能编译成类型化 harness、编译门拒绝任何没有原文引用的规则——构建期闸门的最近先例，对象是单个 skill。**HarnessBank** 维护 harness 基因库，用显著性门（Δ̂>0 且 z≥1.96）在昂贵评测前筛变异，报告有门时"假精英"为 0、无门 +2–3——**本综述里唯一一个接纳信号是统计检验而非裸分的系统**，并且点名拒绝非退化判据（床是 Terminal-Bench / SWE-bench，不处理截断）。**AgentDevel** 把自演化重框成发布工程：版本化规范、症状级诊断、回归感知的门控晋升。另有三篇绕着本文结尾的问题转：*Do Agent Optimizers Compound?* 问多轮优化器增益能否跨轮累积（= §6.7 的踏车，作为 benchmark 问题）；**Red Queen Gödel Machine** 让评估器与被评估者共同演化以防对静态 judge 过拟合；**EMAS** 把轨迹转成结构化诊断、诊断跨样本复现并通过验证才许落地，**WLML** 先把失败归因到节点和机制再修——两者都是朝"读证据而非读分数的接纳"迈的步子，**都不读执行过的图**。

**生成 vs 接纳**——贯穿本节且最容易丢失的一个区分：GEPA **读执行轨迹**，但只用来**生成**候选；接纳仍是分数上的 Pareto。好几个系统用轨迹文本来提议。**没有一个是以"它的机制在执行中确实触发了"为由接纳候选的。** 本节调查的每个系统，选择信号全是聚合分或 Pareto，HarnessForge 也不例外；**HarnessBank 是唯一例外，而它接纳的依据是对同一个分数做的显著性检验。**

### 2.2 故障归因：从平坦日志到因果图

**平坦文本在自己的数字上失败**：MAST 建多 agent 失败模式分类。**Who&When 报 14.2%** 步骤级准确率。AgenTracer、RAFFLES 改进方法。**TRAIL 在自己的 148 轨迹 benchmark 上，最好模型约 11%** 的定位。

> 这是这个领域自己的数字、在自己的 benchmark 上，也是这条路线转向的原因。

**领域自己的答案就是结构**：CHIEF 在标题里就把这一步说明了。FALAT 跟进。**GRADE 把边分级为 observed / declared / inferred**——本文"声明对观测"对账的直系祖先，也是"重建误差在这条线上是被公认的代价"的证据。

**最近的反例，点名**——有四项工作确实把归因接回了修复动作，"归因是离线的、事后的"这句话对第一波成立、对它们不成立：

- **AgentDebug**：检测 → 归因 → 恢复 → 重跑
- **DoVer**：在可疑步骤介入、重跑、数单次介入翻转
- **CausalFlow**：步骤级反事实责任，喂给修复与训练对
- **FlowFixer**：符号化根因 → 执行前过滤 → 验证过的修复，无 judge，跨三个平台报 **71.3%** 修复成功率

**Causal Agent Replay 刻意不在这个集合里**：按我们自己的阅读它停在诊断、没有在活系统里复现。它只作为机制移植的供体进入本文。

**在这四个反例逼出的精度下，位置必须分四条说**：

1. **原生记录**。U 由 harness 运行时写，每条边是 observed 级，重建误差为零。GRADE 的三级边分级就是这个痛点的显式化。而且被记录的对象是**动态展开的执行**，最近的邻居们推理的是静态编排图。
2. **跨任务种群聚合**。lift、锥 diff、回归账都在整床上算。四个反例里三个是单轨迹诊断；例外 FlowFixer 跨的是平台，不是一个演化系统内部的一张床。
3. **读写闭合**。证据喂 Evolver、过闸门、经事务性 apply 落进配置，基因型图与 U 配对。它们的图落回的东西不在 harness 里持久化。
4. **常驻、跨轮的干预**。编辑留在装着的状态、每轮被重新审判，而不是修一条轨迹一次。**这可检验**：一个干预是常驻的，当且仅当它活进第 k+1 轮的配置。

**优势最大在哪、最窄在哪**：四个反例里 **DoVer** 精神上最近（介入并重跑，这就是疗效读数的形状），也正是四条上距离都最大的那个：它的图是事后从单条轨迹重建的、介入是对那条轨迹的一次性重跑、学到的东西不落进任何 harness、下一轮不被重审。GHX 边在发生时记录、跨床聚合、写进配置、每轮重审。对 **FlowFixer** 距离更窄，如实说：它符号化、无 judge（GHX 的门也是），71.3% 修复成功率是本文没有等价物的数字；它缺的是**常驻**——修复只在一个平台的一条轨迹上验证一次，不活进会重审它的环。

2026 年一篇综述直接说：归因与自演化是**互不相连的两条线**——本章就是围绕这句话建的，下面的接头就是它留下的空。

**本文补上的接头**：文献**离线地、在为归因造的 benchmark 上**测归因准确率，报 14.2% 到约 11%。第 3 章测的是这个领域没测过的东西：**当这个质量的信号被接进一个活的保留环**——被 planner 消费、被逐字引进候选文档、并被踩着上车——会发生什么。仪器已经被量化过，**部署它的后果没有被量化过**。

### 2.3 执行溯源与 AgentOps

一条平行线把执行记录当一等设施：OpenTelemetry 的 `gen_ai` 语义约定、AgentOps 分类、基于 eBPF 的可观测性。

2026 年该线的一篇综述把执行溯源定义为六类边上的类型化执行图——并发现它**只服务于人类的信任、审计和调试**。归于该综述、截至其 cutoff，而不是在这里断言为普遍主张：**没有已发表工作把溯源闭合进自动化改进环。**

> 这句话是 GHX 的直接动机，也是本章里唯一一处由别人而不是我们来陈述这个空隙的地方。

### 2.4 结构化候选空间

这条线里有两个系统是 GHX 的**供体**而非邻居，各自分析到"拿了什么、改了什么"的层级——贡献的诚实陈述取决于这个层级。

**MermaidFlow：拿了什么，改了什么。** 它把 workflow 表示成 Mermaid 图，六类类型化声明单元，边带类型约束的执行流和数据标签，用图编辑算子（crossover / mutation / insert / delete）在验证器下演化。验证器是**语法级**的：五条正则实现的软检查（接口存在、问题→返回连通、类型归属、类型合法、集成入度）+ Mermaid 编译。这就够把有效候选率抬到 >90%（AFlow 约 50%），均分 80.75 对 78.67。**拿了**：候选空间应是验证器下的图编辑而非自由文本这个前提，以及算子词汇——GHX 的七个类型化操作就是这套词汇特化到 processor 平面。**改了**三样：对象是 harness 组合层而非逐任务 workflow；验证器是语义的、构建期的（写→重载→重建图往返、对旧 runloop 的 parity door、哈希契约测试）；身份问题被当真——MermaidFlow 的闭包引理说验证过的编辑"无需重验"即可组合，但按我们的机制级阅读，实现对每个候选**全量重跑 checker**：无增量重验、无图哈希身份、无声明↔观测对账（系统里根本没有执行轨迹）。这三样正是 GHX 加的，**正面冲突点也在此：在组合层"免重验"不成立——改一个 processor 的顺序会改变后面每个 processor 看到的东西。**

**AgentFlow：拿了什么，改了什么。** 它的Agent 依赖图（ADG）从异构 agent 框架里恢复六类类型化节点（agent / prompt / model / capability / memory / policy）和**三族强类型边**：组件依赖、带守卫的控制流、含状态读写的数据流。静态、无 LLM、按设计过近似——"可能的依赖，而非单条具体执行轨迹"——60 个框架 59 个成功、中位 17 节点 28 边，喂 BOM 和污点分析。**拿了**：三族边逐字采用（§4.2），以及给 GHX 数据边语义的"到达定义"式状态读写处理（§4.3）。**改了**它每一条设计选择的方向：AgentFlow 离线、静态、可能；展开图 U 在线、具体、观测——运行时为一次调用写下，边只在依赖真发生时存在。AgentFlow 的产物是给人读的报告；U 是给接纳门读的。它的节点词汇刻意不采用（描述的是设计空间，GHX 要描述一个在跑的 harness，节点类型是 harness 自己的：钩子点、processor、slot、bundle、skill、tool）。**关系和归因线那条一样：AgentFlow 是静态过近似，GHX 是它的动态单迹对应物。**

**模块化设计空间系统**（AgentSquare、MaAS、EvoFlow）在模块级类型化候选、在超网上搜索。**接纳仍是 benchmark 分数，没有一个读执行过的轨迹。**

> 这条线买到的是候选空间的**合法性**。**没有一个把类型化候选连到"它触发了"的证据上。类型化管的是可以被提议什么，从不管实际发生了什么。**

### 2.5 图记忆与经验复用（边界，不是第五条路线）

**MEGA** 是唯一满足三条事前定好的判据的邻居——证据图、其上的精炼、跨轮持久化。但它的图是 LLM 蒸馏的**知识**、不可干预；GHX 的是执行级的、支持 do 式查询。**区分在于能对图问什么，而不在于一个测到的下游增益**——这与本文自己"是合法性与身份、不是触及范围"的主张一致。

GraphMind 复用获胜子图，喂 GHX 的一条引导通道。EXG 把执行历史组织成经验图——但对象是检索记忆、不是可执行任务图，复用是检索而非接纳。

> **边界**：这条线演化 agent **记得**什么；GHX 演化 harness **是**什么。这个区分值得握住，因为本研究里唯一产出正结果的通道，落在了记忆那一侧。

### 2.6 定位

位置是那个合取：**执行溯源（记录）× 自动归因（诊断）× 写回持久 harness 的类型化图编辑（编辑），闭合成一个环。**

> **主张是：没有任何在先系统同时持有这全部——不是说其中任何一项是新的。**

不给表格，"位置空着"就是委员会要打破的那句话。所以给表，让步写在里面：

| 系统 | 原生记录 | 跨任务聚合 | 写回持久 harness | 跨轮常驻 |
|---|---|---|---|---|
| HarnessForge | — | ✓ | 部分 | ✓ |
| AgentDebug | 重建 | — | — | — |
| DoVer | 重建 | — | — | — |
| CausalFlow | 重建 | — | — | — |
| FlowFixer | 符号化 | 部分 | — | — |
| **GHX（本工作）** | **✓** | **✓** | **✓** | **✓** |

"部分"是让步不是擦边：HarnessForge 确实写回，但写进一个无构建期验证、无图哈希身份的**无类型文本三元组**；FlowFixer 确实聚合，但跨的是**平台**而不是一个演化系统内部的一张床。表里每个归因系统都持有诊断腿和一部分记录腿；**没有一个写进一个会持久的 harness**。

**四处正面冲突**（直接接下，不绕开）：自由代码候选空间（ADAS / DGM）——本文主张候选应当类型化；**自然语言 harness（NLAH）——本文主张约束不能机器核查的 harness 就不能被门控，而它自己的附录就是这么说的**；知识级图（MEGA）——本文主张图应当是执行级；只看分数的闸门梯（AlphaEvolve、HarnessBank）——本文主张闸门应当读执行而不是读分数，**HarnessBank 的显著性门是它反对的立场的最强形式：对一个不是机制单调换能器的分数（§6.8）做显著性检验，是对错误量的严格检验。**

**移植登记**：11 个机制从本文自己这条线之外借来，每个点名供体，好让没有一个借来的想法被当成这里发明的。（in-run 冗余护卫、无据答案闸门、模型节点意图标注、获胜子图反馈、类型化证据原子、症状到桶映射、锚定 fork 回放、边级 do 算子、留出终闸、跨模型迁移检验、免费同胞对照。）Anytime-valid 序贯检验作为包络闸门的先例列在登记旁。

**对本综述的告诫**：2026 年的 preprint 未经评审。这是跨上述路线的三路扫描，不是系统综述。自改进的强化学习一侧只在边缘扫过，任何"位置空着"的主张都按此定范围。

## 第 3 章 · 基线诊断

> **章主张**：照发表的样子跑，官方环是一个**通过噪声仪器测量的开环**，从"在唯一可核查的子集上四次错三次"的证据里开处方——而它唯一一次真修复证明了：**信号干净时机器是工作的**。

**本章不依赖第 4 章造的任何东西**：每个发现都在无图基线战役上建立，用读环自己原始轨迹的脚本。这个独立性是刻意的——**诊断必须在治疗被描述之前站住，否则治疗就成了相信诊断的理由。**

### 3.1 官方环做对了什么，以及 release 在哪里偏离论文

后面的诊断很重，没有前面的记功会被误读。released loop 是第 2 章调查里**治理最仔细**的自演化 harness，它六条设计选择是本文保留、借鉴、或希望邻居也有的：

1. **它消化成功。** 三套模板（全败 / 全过 / 部分），全过模板要它"别庆祝"、点名可复用策略和潜在脆弱性。多数系统只读失败。
2. **它选择性地调用自己。** 每轮可行动性由档案构成机械算出，低于阈值跳过演化。不为了编辑而编辑。
3. **每个角色在作用域门后面。** 不许读 harness 源码、不许读别的 run，连 shell 命令里的绝对路径也拦——防 prompt 注入和跨实验泄漏，本文自己的登记错误 13（§7.2）证明这是必要的。
4. **五道确定性门，便宜的先跑。** 结构门强制 12 条证据不变量（引用锚必须在盘上存在且指向轨迹内、manifest 必备键、桶与文件类型一致、血统引用可解析）；新颖门对文件改动哈希、拒绝已在驳回账本里的；规范化后**反事实门**把提议的 processor 链回放在上一轮通过任务的记录事件上，输出或退出原因任何变化即拒——不调模型、不执行工具；合成任务回放收尾。
5. **Critic 会和 Evolver 争。** 对着候选将落入的配置逐个判、要求工具/processor 候选给往返证据、可质询 Evolver 两轮、上车前把候选当集合对着 scoreboard 审。
6. **上车的候选要对自己的预测负责。** 每个点名它预期要翻的任务，下一轮给这个预测打分，命中率低于一半触发回滚。

> 第 4 和第 6 条是本文第六道门和定位指标的祖先——正因为它守得这么严，才是问"这些守卫看得见什么"的合适对象。

**release 在哪里偏离论文**（附录 A 逐条钉到行）：GAIA 头条依赖的**变体池 / 集成路由不存在**（release 是单一血统、`ship | no_op`）；**全局棘轮未实现**（顶上去的是相邻轮建议性观察名单 + 反事实门 + 命中率回滚）；**±5% 噪声阈值未实现**（三态离散化 + Critic 提示里一句话近似）；**每格三个种子**是论文的表，代码默认 k=1、焦点集升到 k=2；Planner 的逐候选 **brief 已退役**，只写一份 landscape、单个 Evolver 会话自定候选数。

> 下面诊断的是 released system 实况。哪条发现依赖上述分歧，就在那条说明。

### 3.2 系统实况

环就是 §1.1 那个六阶段四角色系统：solver 批 → Digester 档案 → Planner landscape → Evolver 候选 → Critic 判决 → 五道门，落地的东西成为下一轮配置。每轮受 token/成本预算和任务数上限约束。

两条架构性质对后文全部重要：

**第一，环通过自由文本编辑自己。** Evolver 不发类型化补丁；它把 manifest 和 `config.yaml` 当散文写，**在那次誊写中幸存下来的东西就是实际落地的编辑**。这不是编辑**面**的局限（面很宽，3.7 节展示环通过它装了一整个新的 processor 类），而是编辑**身份**的局限。**下游没有任何东西能确认候选文档和实际应用的改动描述的是同一次干预。**

**第二，环是单一血统。** 一份配置逐轮演化。没有种群、没有备选档案，而且——**尽管论文这样规定了——没有全局棘轮**保证第 k 轮解出的任务在第 k+1 轮仍然解得出。一个落地且错误的候选下面没有地板。

### 3.3 开环风险：反馈写了但没送达

四条通道各自打断了送达。**四条都是代码钉死的事实**：它们是 released tree 的性质，与飞了哪个战役、配了哪个模型档位无关。

- **回归报告被一个轮次索引 off-by-one 弄空。** 环每轮计算哪些原本通过的任务开始失败——正是一条没有棘轮的血统最需要的信号。轮次索引差一导致比较是对着**空集**做的，所以报告**结构性恒为空**。作者自己的上游修复已被采纳，本文每一笔回归账都是离线重算的。
- **判决契约被陈述了两遍，两份陈述已经漂开。** 角色被指示发出的 schema 和消费方校验的 schema 不再一致。校验因此**软失败**：结果被丢弃而不是抛出，**下一个作者永远不会被告知上一次编辑的下场**。
- **安全钳在调试规模上无法咬合。** 回滚只在通过**率**下降 ≥0.05 **且**通过**数**下降 ≥3 时触发。在冒烟轮跑的三题床上，掉 3 意味着丢掉全部通过的任务，而三题过两题时这个条件**算术上不可达**。**钳子在它存在的理由那个场景——新接线、首次运行——里是死金属。**
- **单一血统，没有棘轮，只由一句话看守。** 论文规定了全局单调棘轮：任何已解出的任务不得交还。代码没有实现这样的东西。它有的是：一份跨相邻轮的**建议性**观察名单（agent 可以宣布回归是瞬态从而推翻它）、一道反事实回放闸门、以及一个在上车候选预测命中率低于 0.5 时触发的事后回滚。**没有一个是地板。**

这件事重要不是我们的推断。**released tree 用一句写在 prompt 模板里的指令（而不是一条代码路径）看守它自己已知最严重的回归**——一次 Evolver 编辑替换了系统 prompt 构造器、从而删掉了一段 23K 字符的注入领域策略，被作者自己记为"灾难性回归……掉了 55%"。而**仓库里唯一提交过的性能数字，是一条记录着两条血统从此再未恢复的 commit message** (F19)。

> **一个不能给自己血统解毒的环，是本文能给出的、支持"把读数挂到保留决策上"的最强论据。**

### 3.4 测量层：三重污染

三件事都是跑出来才发现的，都被加固过，而**每次加固都同等施加于两臂**，所以没有一件能成为臂间差异的来源。

- **Judge 假阳能翻转一轮的符号。** 打分由 LLM judge 做，未加固的 judge 其假阳大到足以反转轮间 delta 的符号。这里用的 judge 经过结构性加固，且本文**每一次臂间比较只用审计过的分数**。
- **床的 ground truth 有一部分在公网上。** 从"会摆动的任务"里组出的 44 题队列中，**12 题是泄漏路径**：它们一半以上的通过触到 benchmark 产物，且参考答案逐字出现在 solver 轨迹里 (F31)。应对是泄漏黑名单 + 去污普查。**残余风险在威胁一节披露而不是被辩掉**：两臂每轮在同一张固定床上评测，所以任何朝床的漂移是共享的，黑名单是唯一的留出防线。
- **重测同一份配置会动 20% 的床。** 这是支配本文每一个实验设计的发现。该战役十六轮读数窗里的六个无 ship 窗内，**21.0%** 的任务结果在两个跑同一配置的相邻轮之间翻转——**600 个任务对中的 126 个**——由此产生的总分摆幅是 **−4 到 +5，完全没有施加任何治疗** (F15)。

> 第三个来源不是加固能去掉的缺陷。**它是仪器的一个性质**，在三个种子上复现，也是本文终止于此的原因。

### 3.5 证据管线审计（本章的正面发现）

Digester 产出的每份档案，对每次工具调用都带一个"输出是否**被用**"的判决。**这是环关于"一个动作是否重要"的唯一信号。** Planner 排名方向时消费它，Evolver 论证候选时引用它，Critic 决定是否否决时复审它。在基线战役的十六个计分轮上，这一列只判定 **8.1%** 的载荷调用被用过 (F1)。**要么 harness 有大问题，要么这一列有大问题。**

是这一列。缺陷可以在三个强度递减的层级上确立。**本文只需要前两层，并且明说，因为第三层依赖一个数据无法提供的前提。**

**(i) 构造**。这一列检验**紧接着的下一条** assistant 消息是否与工具输出共享 **≥20 字符**逐字子串（`harnessx/aegis/stages/trace_facts.py`）。三种真实使用因此**按构造**被判"未引用"，不需要任何数据就能看出来：被转述而非引用的使用；发生在下一步之后的使用；**以及任何短于二十字符的事实的使用**。

**(ii) 在这张床上的失明**。第三种在这里不是角落情况。**GAIA 最终答案中位长度 9 字符、90 分位 14 字符** (F3)——两者都低于这一列自己的地板。一次取回任务答案、并交给一个正确使用它的模型的工具调用，在下一条 assistant 消息里产生的字符串**短到过不了阈值**。

> **在这张床上，这一列无法登记一个答案的使用。**

(i) 和 (ii) 合起来就定案了，而且**不需要任何实验**：第一个是代码的性质，第二个是 benchmark 的性质。**两者都不依赖飞了哪个臂**（都在无图基线上建立），**也不依赖模型档位**——二十字符的地板和九字符的中位答案，不会因为哪个模型读摘要而改变。

**(iii) 比率，以及它不授权什么**。在 **559** 次"输出字面包含一个通过 rollout 最终答案"的调用中，**419 次（75.0%）**被判"未引用"，其中 **96.7%** 携带的答案短于这一列自己的最小长度 (F2)。这个数字在答案长度窗口的各种变体下稳健在 **73.8–75.1%** (F2)；这一列自己的二十字符阈值没有被扫，而按 (i)，扫了就等于换了仪器。

> **限度，明说**：一次输出含答案、走在通过路径上的调用，是一次**坐在成功路径上、手里拿着答案的调用**。这和**导致了通过**不是一回事。所以发现落在 (i) 和 (ii) 上（它们不需要任何因果前提），而 **75.0% 是作为这一列输出的一个性质来报告的**——它把判决打在携带答案调用上的比率——**不是作为被错误否定的工具调用的计数。**

**免责声明，以及它为什么让情况更糟**。Digester 自己的文本确实带一句告诫：

> *启发式*：工具调用之后的 assistant 消息不含任何来自工具输出的 ≥20 字符子串。这是工具调用"触发了但没能影响模型"最常见的方式——例如协议扁平化丢掉多模态内容时。

**这句告诫就是缺陷的缩影**。它点名了一个失败模式（多模态扁平化），**从不提及任何低于二十字符的答案对它都是不可见的**，而床的中位答案是九。它把这一列描述成在**检测触发但未影响模型的调用**，而这恰恰是 (ii) 所禁止的解释。而且**它不随判决一起走**：档案主表里的逐调用行只有一个光秃秃的 **NO**。

**伸进决策**：这个判决抵达 **86.0%** 的档案 (F4)、被逐字引用进三份候选文档 (F5)、**有一个候选踩着它上车了** (F6)。

那个上车的候选点名了三个它预期会翻转的任务，**一个都没中**。**这是作为图示报告的，不是作为推断**：对着该轮 7/32 的底率，一个毫无效应的候选三中零的概率是 **0.48**。这个标本展示了一列假信号如何传播进一个上车决策；它对那个决策好不好只字未言。

### 3.6 决策面的病

- **灭因账写了从来不读。** 环维护一份"每个候选为什么死"的记录。**没有任何东西消费它。** 写入点和缺席的读取点都在附录里给出。这是第 3.3 节四条断裂送达通道中最直接的一条：**环给自己的失败记日记，然后不打开。**
- **瞄准者看不到瞄准的落点。** Planner 被结构性地排除在环的转化先验之外——引导 rebind 列表漏了它（`planner.py:30--46`），各臂皆然。决定瞄什么的那个角色看不到以前的瞄准落在了哪里，所以环学到的“哪些目标会转化”从未到达选目标的那一阶段。

### 3.7 唯一一次真修复

对着以上全部，基线战役里有**一次干预可证明地起效了**，而它是本文最重要的单次观察——**不是因为它的尺寸，而是因为它是唯一一个标定了仪器的事件**。

缺陷很平庸。harness 的 Bash 工具有个 shell 引号 bug，导致命令消耗轮次 token 预算而不产出有用输出，所以任务死于**预算饿死**而不是死于任何与难度有关的东西。环诊断出来、撰写了一个护卫 processor、把它上车了。在接下来那一轮：`budget_exceeded` 退出从 **35 塌到 4**；**十六个新通过的任务里有十二个**在前一轮死于饿死；L2 子集涨了 **16.3 个百分点**；总分升了 **9** 题，跳出同配置带 (F39)。它是该战役基线抽样之后的**最大单轮移动**，也是全部六个战役六次整床带外移动中**唯一一个机制在退出账上可读的** (F48)。

**哪个数字承载本节**：机制终点，把 +9 放在**旁边**而不是**底下**。38→5 的塌缩和十六中十二的归因**直接标识机制、根本不需要任何离散度论证**。+9 与它们一致，并跳出同配置带。

**跳出带这件事本身比看起来弱**。全战役轮对扫描找到 11 次带外移动，**其中 6 次发生在什么都没上车的轮次** (F48)；而在饿死数塌掉 ≥10 的整床轮次中，分数分别动了 **+9、+4、+2、−3** (F49)。**是机制计数、不是那条带，把这次移动系到这次修复上的。** 带在这里的角色更窄但仍必要：它是让分数效应**根本可读**的东西，而本文余下部分讲的就是那有多罕见。

**两把口径对它意见不一，而分歧被陈述、不被解成对本文有利**：从几个窗口抽出的极差不是标准差；第 5 章直接实测的 σ = 3.70 把 +9 放在三个 σ 之内。这次修复在两把口径下都靠机制计数站得住。口径改变的只是**一个效应要多响，分数轴才听得见**——而那个问题、不是这次修复，才是本文的主题。

**怎么读它**：这是一次工程缺陷修复，不是能力提升。环没有变得更会解 GAIA 题；它只是**停止浪费它解题所需的预算**。但它也是保留机器完好的存在性证明：效应大到足以被看见，它被看见了，药被保留了该战役余下全程。

## 第 4 章 · GraphHarnessX：图原生 harness 运行时

> **章主张**：执行成为一等的、机器可查询的对象，从外部挂在未修改的官方环上——以读数阶梯作为系统的组织框架，每条机制主张由一份活体记录承载。

本章按**纪律**而不是按功能清单组织。每节陈述造了什么、有资格主张什么、以及在诚实答案比显然答案更窄的地方**没有资格主张什么**。构造性局限在本章披露而不推给威胁一节——**因为一个源自设计决定的局限，属于那个设计决定的旁边。**

### 4.1 五条设计约束（写码之前定死）

- **字节钉死的底座**。官方系统在固定 revision 下 vendor，由 sha256 manifest 和测试套件强制。基线臂跑的因此是**作者的系统**，不是我们对它的理解。没有这条，每个臂间差异都与我们自己的维护混淆。
- **零核心编辑**。vendored tree 一个字节都不改。每个 GHX 机制挂在 seam 上。**这是让第一条可核查而不是仅仅可期望的东西。**
- **seam 在 `finally` 里恢复**。崩溃不得给下一轮留下一个被改过的环。恢复是无条件的。
- **旗标默认关**。臂分离是配置的性质，不是操作员纪律的性质。一个不设任何旗标飞的战役，行为上与官方系统字节等价。
- **一道从未被看见失败过的闸门还不算闸门**。这里加的每道接纳闸门都做变异测试：一个刻意畸形的候选必须被拒、且拒绝被记录，闸门才算存在。

### 4.2 类型化可执行组合图

harness 的配置被重新表达为类型化图。**六类节点**覆盖可执行面：十个固定 runloop 钩子点、processor、类型化 slot、bundle、skill、tool。**十二类边**连接它们——十类声明的或结构的（挂载、排序、声明的 slot 读写、成员、互斥等），**两类在运行时观测**（控制、数据）。

AgentFlow Agent 依赖图（ADG）的三族强类型边被直接采用；它的节点词汇**刻意不采用**——那套词汇描述的是一个设计空间，而这里必须描述一个具体在跑的 harness。

两条性质由测试强制：**单一排序权威**（图是唯一决定 processor 顺序的东西，所以图和执行的管线不可能不一致）；**parity door**（同样输入下，图驱动和原始 runloop 必须产出字节相同的行为）。

### 4.3 展开执行图 U

组合图描述 harness **是什么**。展开执行图 **U** 记录它的一次调用**做了什么**：一个跨 processor、工具调用和嵌套 agent 的有向无环图，由运行时在执行推进时写下。

**无环是构造性的而不是检查出来的**：每个事件拿一个全局序号，边只从低往高走，所以环**无法被表示**。数据边由**到达定义**计算——某个 slot 的最后写者连到它的每个读者——并与运行时自己的 slot 溯源交叉核对。

**三条诚实规则**统治记录器，它们作为规则被呈现，因为它们正是 U 能被当作证据用的理由：

1. **边永不被发明。** 一条边存在于 U 中，当且仅当运行时观测到了它代表的依赖。
2. **无法归因的事件标 `UNGRAPHED`，而不是给一个看着合理的标识符。** 记录器**被允许说它不知道**。
3. **跨层前沿被报告，永不被静默穿越。** 图的知识在哪里终止（嵌套 agent 边界、外部调用），那个边界就出现在记录里。

> 这些规则**花掉覆盖率、买到可采性**。一张会猜的图不能作为接纳闸门的输入，因为一道信任猜测边的闸门是一道可以被绕过去说服的闸门。

### 4.4 身份：三层嵌套哈希

一个通过自由文本编辑自己的环里，三个关于候选的问题会互相混淆：这是不是我们以前见过的同一个提案、这是不是我们实际部署的同一个东西、它的行为是不是一样。GHX 用三层嵌套哈希把它们分开：

- **基因型 Genotype**——配置的结构身份，排除只在运行时存在的 processor。**同基因型的两个候选在结构上是同一个候选。这是去重键。**
- **部署 Deployment**——基因型 + 运行时覆盖：**实际跑的是什么**。
- **表现型 Phenotype**——部署 + 观测到的执行边：**它实际做了什么**。

包含关系 genotype ⊆ deployment ⊆ phenotype 由哈希契约测试钉死。最近的先例是 DGM 的档案身份；**区别在于这里的分层是为了把"声明"和"观测"分开——正是自由文本编辑面所摧毁的那个区分。**

### 4.5 执行图上的因果查询

环需要、而在平坦日志上无法表达的查询是：**给定这次失败，什么可能产生了它？** 在 U 中这是失败事件的**祖先锥**——它上游的一切。全锥跟随控制边和数据边；数据锥只限于数据流。

**锥很小**。在图战役早期失败队列上（n=33，R0–R1），中位轨迹是 **1,186 节点、606,000 字符**的记录，而它的全锥是 **48 个节点**、数据锥 **42** ——约为该次调用的 **4%**。

> **情态措辞是承重的，全文一律保持**：锥是**可能塑造了**这次失败的东西，**从不是导致了它的东西**。在记录器的诚实规则下，锥是因果祖先的一个**可靠的过近似**。**它不是反事实，本文没有任何地方把它当反事实用。**

### 4.6 证据集成

失败锥与跨任务事实被注入 Digester 和 Planner 的上下文。**通过的任务作为对照侧进入**而不是作为自己的档案：通过锥签名喂 lift 对照（没有它们，lift 显式地不计算），加上记录"某任务的锥自上次通过以来获得或失去了什么"的 flip diff，以及通过/失败两个种群之间的划分线。**官方 Digester 自己对所有结果的消化保持原样不动，所以下游没有任何东西改变形状。**

第 3.5 节那列假信号被替换。跨修复后的图战役，**859 份档案中 0 份**携带它 (F7)，对无图臂的 86.0% 触达 (F4)。每次注入都记进 manifest，所以"这个角色实际看到了什么"这个问题有一个**不依赖于相信该角色自述**的答案。

**这是一次表示变换，不是更多信息**。对任何证据注入结果最显然的反驳是：被治疗的那臂只是被给了更多东西读。这个设计先按构造、再按测量堵死它。**按构造**：渲染出的锥是**地图不是载荷**——它携带结构和标识符，**不复制任何轨迹内容**。**按测量**：中位渲染锥 **15.5 kB**，对着它争夺同一份上下文预算的 **87.4 kB** 轨迹——**比值 0.12**（n=44, R1）。

**证据变小了、也更有根据了**。四个独立测量指向同一个方向：

- 锥是调用节点数的约 **4%**；
- 渲染锥是轨迹字节的 **0.12**；
- **k=1** 的观察就足够让环够到正确的药系——更多轨迹买到的是论证质量，不是新药系 (F26–F30)；
- 图臂的摘要每份携带 **3.50** 条已验证引用锚点，对无图臂的 **1.75**，同时摘要未通过生产锚点校验器的比例从 **11.7% 降到 1.5%** (F52)。

> 合起来它们说的是比"图有帮助"更窄也更站得住的话：**把证据结构化，使其体积下降一个数量级，同时提高其引用的密度和有效性。** 这是一个关于**证据**的主张，而且是测出来的。它是否改善结果是另一个问题，在第 6 章以否定回答。**哪个组件赚到了这个引用改善是第三个问题，本文拒绝回答——因为没有任何一臂隔离了三个候选原因。**

### 4.7 验证面

**为什么要第六道门**。官方结构门已经检查候选的证据存在——但是作为**文本**：引用必须解析到一个文件和其中的步骤索引。它问不了"候选说要修的组件，在它引用的那次失败上**执行过**吗"，因为官方记录里执行只以散文形式存在。白名单记录说明这个问题为什么要紧：三个图种子上，**18 个候选过了全部五道官方闸门，随后被发现声称要修的节点从未出现在它引用的那次失败的执行图里** (F53)。第二个理由是官方梯自己的一个陷阱：vendored 回放门跑的是一个琐屑合成任务（"Reply with exactly: OK"，两步），里面新工具永远不会触发，拿**那个**执行去查工具候选会把它们全杀掉。所以第六道门定义在真实任务的回放图上，没有图时如实说没有。

**第六道接纳闸门**。官方梯有五道闸门，**全部读候选的散文**。第六道在记录的失败执行里**数候选自称的目标**：如果一个候选说它在修某个节点，那个节点**必须出现在它声称要修的那次失败的图里**。在没有回放图的地方，闸门记一次**诚实通过**（`checked=False`）——它放行候选，并记录它没能检查。**它绝不报告自己检查过而实际没有。**

**带活体拒绝记录的回放闸门**。十五次检查中，**七次**产生了形如"改了，但从未跑过"的结构性拒绝，**没有一个被拒候选上车** (F11)。这些拒绝就是"闸门存在"的证据。

> **拒绝的正确性未经验证，并如实声明**。每次拒绝依据的是单次回放抽样，没有跑反事实批次来确立被拒候选确实会失败。**闸门被证明会触发；没有被证明触发得对。**

### 4.8 类型化候选面

候选成为**类型化图编辑**，撰写时验证、再渲染回官方格式，所以下游什么都不变。

**对着正确的基线陈述**。变的**不是编辑面的触及范围**。类型化候选空间在文献里已经存在，更重要的是——**官方环本来就能做这件事**。在无图基线臂里，它把新的 processor **类**作为源文件撰写出来，通过 `config.yaml` 里的 `file://` 目标装进去——其中就包括本文唯一一次超噪声修复背后的那个护卫 processor，另外还有一个死胡同执行器、一个工具循环打断器、一个证据闸门、一个数值校验器。**`processor` 是该战役最大的候选桶。GHX 贡献的无论是什么，都不是"能加一个节点"这件事。**

变的是编辑**如何被提交和被识别**。官方路径下，Evolver 把 manifest 和 `config.yaml` 当自由文本写，候选真正的编辑**是它自己誊写之后幸存下来的东西**。GHX 下，每次变更都是 processor 平面上七个类型化操作之一——`insert_node`、`remove_node`、`replace_same_group`、`change_dependency`、`swap_subgraph`、`mutate_inactive`、`mutate_params`——作为一个原子组通过五阶段事务提交**或整体拒绝**，两份产物每次调用都**机器生成**，并有一次 写 → 重载 → 重新建图 的基因型往返来验证这次写。

诚实规则延伸进环所读的工具文本本身：`mutate_inactive` **不验证 inactive 并在自己的描述里明说**；下划线前缀的元数据被**直接拒绝**而不是静默接受。

**覆盖，诚实陈述**：类型化面**比官方自由文本面更窄**。七个图操作覆盖 processor 平面；两个 config section 操作覆盖 tools 段；prompt 编辑作为 prompt processor 模板上的 `mutate_params` 进入。**编辑 harness 自己的源代码完全在范围之外**，并记为一条偏离。

> **GHX 把官方动作空间的一个切片类型化了。它没有扩展这个空间，而这个切片就是主张。**

**运行时策略引擎**。图还支持由环自己填的规则槽。标本是环在跑动中撰写的一条规则，它在 10 个任务上**触发 19 次、零附带损害、零转化** (F11)(F20)。

> 诚实地读：**大量触发，无害，无治愈**。这是一个**活性证明**——通道从环自己的推理到一条活的运行时规则端到端通了——**不是一个成功故事**。

### 4.9 读数阶梯（本系统的组织框架，也是本文向领域提出的框架）

- **L0** 它在部署配置里吗？—— 落地闸门
- **L1** 它曾经执行过吗？—— 回放闸门；活的，七次拒绝 (F11)
- **L2** 它触发了吗，在什么上？—— U 上的触发数与假阳数；**由环自己产出** (F38)
- **L3** 触发改变结果了吗？—— 带触发归因的同窗配对试验；本文中**手工**造出并执行 (F34)(F36)，**从未接进环里**

**作为标准提出，不是作为内部脚手架。** 证据级别阶梯在别的领域做承重工作——临床医学的 GRADE、驾驶自动化的 SAE J3016——**正是因为它们迫使一个系统声明自己的主张站在哪一级上**。

第 2.1 节调查的**每一个**自演化 harness 都在 **L0** 接纳候选：检查编辑落地了，然后按聚合分选择。**没有一个报告 L1 或以上。** 阶梯的贡献是：**声明级别现在既可能又便宜**——给定一张记录的执行图，L1 和 L2 是机械的。**L3 是本文证据认为剩余努力应该去的地方。**

### 4.10 构造性局限（在这里披露，因为它们是本章决定的后果）

- **移除不是测量。** 替换掉假列的那一列在滑动窗口下**按构造饱和**：它把 **549/549** 次调用标成被用过 (F8)。假信号消失了，这可验证；但**替换品不携带任何信息，所以它的存在不能被读作对任何东西的测量**。第 6 章在报告移除结果的那一处就说这句话，不只是在这里。
- **记录器门控的休眠。** 关掉 unfold 记录时，运行时规则**是哑的**。这是 GHX 自己引入的一条静默丢失通道：一个编辑可以被部署、通过每道闸门、然后**从不说话**，因为让它说话的那个记录器是关的。已披露，并在疗效试验中被计入 (F36)——**在那里它确实起了作用**。

## 第 5 章 · 实验设计

> **章主张**：功效算术先于终点——在一张同配置翻转率 20% 的床上，≤5 题的总分 delta 不可读；所以设计要配对、预先设定终点、交错窗口、数触发、并审计评测者本身。

多数实验章描述测了什么。**本章从确立"本来能测什么"开始**，因为在这张床上这个问题有一个令人不适的答案，而后续每个设计决定都由它推出。

### 5.1 床、臂、开关梯

床是 GAIA 纯文本切分的 **100 题无图像子集**。比较在"官方系统 + 所有 GHX 旗标关"（**无图臂**）与"同一系统 + GHX 开关逐级打开"之间——记录、图证据、图验证、类型化候选面，**每级保留其下各级，从不一次全开**。

**六个战役可作证**：无图基线、修复后的图战役、以及两对复现（各以未修改的两臂配置重飞十六轮）(F44)(F45)。两个早期图战役是试航（图层还带着落地和账本缺陷），由口径裁定从本文每一个数字与叙述中整体排除。全程审计打分。

**一个分母管全部**。两臂飞的**不完全是同一张床**：GAIA 纯文本切分有 103 题，其中 3 题带图像内容、图记录器无法归因；无图臂在前两个种子上把 103 题都试了，图臂只试没有那 3 题的 100 题；第三种子的无图臂在第 7 轮中途被移到子集上。环自己的 `curves.json` 记录的是每轮**实际飞的那张床**，所以**那些数字不能跨臂比较**——在第三种子上甚至不能和自己比。

> **本文每一次跨臂读数因此都从 `task_history` 在 100 题无图像子集上重算**——这是所有六个战役共同的有序子集 (F46)。

这 100 题中 **97 题可达**：3 题在六个战役 9,600 次任务评测中从未被解出、贡献零方差，所以本文报告的每一个**差值**在 97 还是 100 上算都相同，**只有百分比会移动** (F54)。**分母仍然保留 100**，因为**基于结果丢弃任务就是选择，不管它看起来多无害。**

**模型，以及为什么是这一对**。每个战役跑同样两个模型、走 LiteLLM 网关，runbook 每条启动命令都记着这一对：**solver = `deepseek-v4-flash`**（284B 总参 / 13B 激活；thinking 开、effort high），**四个元角色和 judge = `deepseek-v4-pro`**（1.6T / 49B 激活）。官方论文唯一完整实验是同样的形状——强元层压弱任务层，Opus 压 Sonnet / GPT / Qwen——但在另一个 benchmark 上，两者只可比形态不可比数字。

solver 档位在任何战役起飞前按公开模型卡定死，五条理由按分量排：

1. **余量。** BrowseComp（最贴这张床的公开基准）上 Pro 83.4、接近开源天花板；这么强的 solver 会把 harness 效应能显形的窗口压平。Flash 在曲线中段（high 档 53.5、max 档 73.2），与调试期的本地先验一致，效应有地方出现。
2. **成本。** Pro 单价是 Flash 的 3.1×，算上 Flash 约 1.3× 的冗长度，每任务约 2.4×——几千次 rollout 下，这是 §6.4 的复现付得起和付不起的区别。
3. **失败签名。** 第三方实测 Flash 工具调用干净（无跑飞重试、无畸形参数），失败落在实质正确性和长上下文检索上——**这是 harness 能作用的失败，协议失败不是。**
4. **唯一文档化的硬伤被避开。** Flash 关 thinking 时长上下文崩塌（MRCR-1M 37.5）；这里每条轨迹 thinking 都开着、都带非空 thinking 块。
5. **两个未知留给 pilot 实测**而不是从没公布的卡上内插：严格最终答案格式依从、20 步轨迹的 run-to-run 方差。**第二个变成了本文的主题。**

元层设成 Pro，是为了读被治疗臂时诊断质量不成为瓶颈：图证据要是没帮到一个强读者，锅甩不到读者头上。**战役前陈述的预期因此克制而有方向**：一个有余量的中段 solver、一个强元层、以及——如果证据真重要——一个会在分数上显形的效应。主张按这一对定范围。记为关于实验的事实而非威胁，因为本文没有任何主张是关于模型档位的。

### 5.2 功效算术先行

**翻转率**。取两个什么都没上车的相邻轮。配置相同，唯一的区别是床被再跑了一遍。基线战役十六轮读数窗里的六个这样的窗内，**21.0%** 的任务结果翻转——**126/600** 对，95% Wilson 区间 **[17.9%, 24.4%]** (F15)。另两个种子是 20.1% 和 19.2%，二十个窗池化是 **20.1%**（402/2,000 对，[18.4%, 21.9%]），三个逐种子区间大幅重叠 (F9e)。

> **噪声地板是床的性质，不是某次跑的性质。**

在这些窗上，**52.3%** 的任务-战役对至少翻转一次。单窗总分摆幅跑到 **−8 到 +5** (F15)(F44)(F45)。

**算术，慢慢走一遍**：

1. 无治疗重测时，五分之一的任务结果翻转。
2. 床因此在两个相同的轮次之间摆动**多达八题**。
3. **任何 ≤5 题的总分 delta 因此作为效应证据不可读。**
4. 分数轴对于这个环所产出量级的每轮效应，**只能返回"不可分离"**。

第 4 步才是要紧的那步，**而且它不是在抱怨样本量**。它是在陈述这台仪器能分辨什么。

**一条包络，一把口径**。摆幅全文一律引作无 ship 窗上的**观测极差**，而极差取决于抽了多少窗：种子 1 **−4…+5**（6 窗），种子 2 **−4…+2**（8 窗），种子 3 **−8…+5**（6 窗）(F15)(F44)(F45)。**本文每一次可读性判断用的带是它们的并集：−8…+5 题**，全文一律这样引；逐种子极差只在描述某个种子时出现。

> **从几个窗抽出的极差不是标准差，而且这个区别不是化妆品。** 三个种子都在一张床上之后有二十个同配置窗，够直接估每轮分数 SD 而不用极差换算：**3.70 题**，三个 σ 是 **±11.1**——**比观测带更宽**。**本文每一次"不可读"的判决因此都保守在"使分离更容易主张"的方向上，而不是更难。** 两把口径对某个具体数字意见不一时，分歧在那个数字处陈述而不是静默解决；唯一出现的一例是 3.7 节的 +9。

**这张床没有一个"既有信息又可靠"的子集**。对一张噪声床最自然的反应是找到它可靠的核心、在那里测。**在这张床上这个反应失败，而普查直说了**：跨六个白名单战役、100 题子集、9,600 次任务评测——**3 题从未被解出、18 题永远通过、79 题易变** (F54)。

> 那 **21** 个稳定任务贡献零方差、因此**无法登记任何治疗效应**。而那 **79** 个**能**动的，恰恰是**不用帮就会动**的那些。**去掉易变族不是在清洁仪器，是在移除仪器。**

床的可靠性在这里**买不到**（靠选题）。它可以靠**重复次数**买——用 Spearman–Brown 对着实测逐题翻转率定价——或者靠**换读数**，那是本文自己的路线。

**同一份数据，两个判决**。一个窗把这点说得很尖锐：一个**总** delta 是 **+7**（在带内，因此不可读）的轮次，分解开是 **8 题修好、1 题弄坏**，在精确 McNemar 检验下给出 **p ≈ 0.039** (F21)。

> **同一份数据，两个判决。问题从来不是数据太少，是读数轴选错了。**

### 5.3 疗效试验协议（手工 L3 的成本）

读数阶梯的第 3 级从环里拿不到，所以手工造了。以下协议就是一次手工 L3 读数的价格，并作为自动化版本的规格提出：

- **两臂在同一窗口内交错。** 串行跑两臂会把臂与时间窗混淆。**这条规则是靠一个结果被它的缺席毁掉才学到的** (F36)。
- **真实完成数在任何打分之前先数。** 启动尖峰死亡和幽灵运行靠逐个检查排除。这是登记错误 **14**。
- **战役的任务参数被精确复制。** 战役跑 `--max-steps 20`；加载器默认 40，**步数预算翻倍、复活了那些原本死于烧穿的任务**，静默地改变了被测量的东西。登记错误 **15**。
- **裁决文件被隔离在受试可达文件系统之外，并植入 canary 词。** 如果一个植入的标记词曾在受试轨迹里浮现，受试就读了它不该读的东西。**登记错误 13 就是这个标本**：一份裁决文件被留在 run root 里可读、一个角色读了答案纸、一轮裁定作废。
- **gold 标签在试验前做健康检查**，遵循考古协议——**一个错误的 gold 标签就是这样被找到的** (F29)。
- **一组八个永远通过的任务作为 canary 检测伤害** (F33)，停止算术决定是否继续，而且**机制终点与分数并排报告**：触发取证，以及**自信错误占比**——受试自信地收敛到一个错误答案的失败比例。

> 最后一条才是让这个协议**能返回一个可解释的零**的东西。**分数平 + 机制平 = 真零。分数动 + 机制平 = 噪声发现。** 没有第二个终点，这两者无法区分——而第 6 章两种各报了一个。

### 5.4 分辨率法则作为设计输入

第 5.2 节的床级翻转率是这个问题温和的那一面。**在任务级更糟**：逐题底率在**半小时窗口之间**摆动多达 **±50 个百分点** (F34)。两个后果被当作设计约束而不是发现来处理：**单窗 ≤5 的 delta 不可读**；**任何疗效主张都需要跨窗池化**。

**多重性，声明**：本文**恰好有一个确证性检验**——**前瞻**疗效批次 **n=70** 对（7 个干净任务 × 10 次重复 × 2 臂），停止规则就是对着它注册的 (F34)。池化的 174 对读数是**支持性**估计，报告它是因为它一致，**不是因为它被注册过**。

本文**其他每一个 p 值都是探索性的**，包括 5.2 节的 McNemar 窗 (F21)、同窗对照 (F36)、笔记通道 (F35)、簇迁移 (F32)。每一个在使用处和这里都标为探索性，**不主张任何族错误率校正**。

> 这一点之所以重要，是因为研究过程中仪器实际做了什么：**四次连续的表观胜利——+7、+5、+4、+6——由三种不同的仪器逐个执行。那四次是对同一个假设的串行重测，而这正是确证终点必须是预先设定的前瞻批次、而不是它们中任何一个的原因。**

### 5.5 评测者偏倚控制

**pass@1 纪律**。混合 k 的通过不算数。把这条规则机械地施加到基线战役的种子轮上，**把它记录的分数从 67 改到 57**：k 混合白送了种子十次通过。

> 这个更正在这里陈述而不是留给读者去发现，**因为它移动的方向**：**降低种子会放大该战役的表观增益——这个更正在讨好本文自己的基线战役。** 规则在两个方向上机械施加，**而这个实例被披露恰恰因为它是机械规则碰巧有利的那个实例。**

**错误登记**。本工作期间记录了 **15 条**测量与设计错误，每条之后强制重查。**两个偏倚方向都有记录。** 十五条中的三条——错误 13、14、15，全部出现在 5.3 节——**不是作者而是导师抓到的**，它们共同的根因记为**"检查停得太早"**。

> 登记本身被当作一项结果对待。**一个评测者本身未经审计的研究，没有资格给出它报告的置信区间。**

### 6.2 图做了什么，没做什么

**假信号消失了**：跨修复后的图战役，**859 份档案中 0 份**携带那列误导性判决，对无图臂的 86.0% 触达 (F7)(F4)。**这是本文最干净的正结果，也是最窄的。**

**非干扰，按构造和按演示**。记录器不得改变它记录的东西。两个论据，种类不同。**按构造**：记录器对环的决策输入是只写的，每个 seam 在退出时恢复。臂间差异只能经由环自己的决策流动。**按演示**：稳定队列上的同窗配对试验——8 个永远通过的 canary + 2 个从未解出的任务，3 次重复 × 2 臂，**记录开关是唯一的差异**——返回 **10 个逐题结果向量里 9 个完全相同**。唯一那次分歧是有记录的不稳定 canary (F33)，而且它**失败在记录关闭的那一臂**。臂总数是 **22/30 对 24/30**：在噪声内，且符号**指向反干扰** (F43)。

> 在一张五分之一结果会翻的床上，**分数相同不是一个可达成的标准**。稳定任务上的**向量级 parity** 是，而这就是采用的标准。

**移除不是测量**：替换列在滑动窗口下按构造饱和，**549/549** (F8)。假信号的缺席可验证；**替换品的存在什么都不测**。任何把 "0/859" 读作"图臂的工具调用真的被用了"的解读都不可用，**本文也没有这样读**。

**引用完整性改善了，功劳归给那一层**。图臂摘要每份携带 **3.50** 条已验证引用锚点，对无图臂的 **1.75**，同时未通过生产锚点校验器的摘要比例从 **11.7% 降到 1.5%** (F52)。大约两倍的引用量、大约七分之一的失败率——**所以这不是上一小节那个饱和陷阱**（那里的干净是靠少引用买的）。

> **哪个组件赚到它没有确立**。三处 GHX 改动都可能产生这个结果：锚点修复 pass（一个独立旗标）、图喂的摘要本身、以及重绑的摘要构造器。**没有一臂隔离它们。** 站得住的主张因此是 **GHX 这一层**改善了引用完整性。**"图"改善了它没有被证明。** 而且因为锚点修复 pass 可以单独开关，**这个增益可能和成本工作一样可移植到未修改的 harness——也就是说，它可能根本不是一个图结果。**

### 6.3 下游：结果不分离；上车更少，但更干净

**定位，以及为什么只有一个数字幸存**。环自己的预测**携带真实信息**。在无图基线上，一个上车候选点名的任务翻转率是 **50.0%**，对着 **25.2%** 的底率——**lift 1.99**，按候选自助法给出 95% 置信区间 **[1.47, 2.54]**（13 个候选、50 次合格预测），**区间排除 1.0** (F9a)(F9d)。

> **这是本文承重的那个定位数字**，而且它与考古指向同一个方向：**基础环已经会瞄了。开处方从来不是瓶颈。**

**臂间比较被撤回，不是丢失**。图臂的 lift **不能放在它旁边**。两个上车集是**不同的候选种群**，在**不同的闸门制度**下被接纳——五道闸门对六道，**17% 被杀对 57%**——且抽自**相差 9 个百分点的底池**。而且图臂自己的区间**无论如何都包含 1.0**，所以即使单独看，这个值也与偶然不可区分。

诚实的收尾数字是这个设计的触及范围：**一个真实的 40% 定位改善在这个样本量下本来就看不见** (F9d)。**这是一次缺席的测量，不是一个功效不足的零结果**，而这个区别不是学究气——**一个功效不足的零结果仍然指向某处，而这一个不指向任何地方。**

**结果**：最终分数不分离。上车率无图 **0.88/轮** 对图 **0.62** (F10)。开关损益账覆盖 **21** 项，**没有一项构成一次测到的行为改善** (F12)。

**上车更少不是退步**。诱惑是把 0.62 对 0.88 读成环变糟了。闸门账的其余部分说不是。跨三个图种子，**第六道闸门杀掉了 18 个已经通过全部五道官方闸门的候选**——十八个被抓到在点名一个从来不在那儿的节点。而候选**死于畸形**的比例——同时未通过规范化、回放和结构检查——从 **18/59（30.5%）降到 8/55（14.5%）**，这是两份产物由机器生成而非誊写的直接后果 (F53)。

> **更少的候选、更高的合法性、多一道闸门。这笔交易值不值，恰恰是结果轴无法分辨的——而这是发现，不是对它的回避。**

**为什么没有组件消融**。读者会要一个开关梯的逐级消融，而"没有做"的理由必须是**正确的那个理由**。

**不是**因为对照臂也在涨——那个事实排除了纯时间趋势，并不会让消融失去信息量。

理由更窄：**消融是把一个臂级效应归因到一个部件上，而在分数轴上没有臂级效应可归因**——两臂坐在同配置带内，所以逐级臂只会一次一级地返回同样的"不可分离"判决，成本是 k 倍。

两个次要点作为设计成本记录而不是作为辩解：这张床上的逐级消融需要**它自己的种子**（每级一个种子无法分辨带内的差异）；而实际飞的对比是一个**旗标 bundle**，所以一个干净的梯必须在一张床上重飞每一级——**一笔可修的开支，本项目没有付。**

本文替换上去的是**记账**，标为 [C] 观察性而不是作为因果分解呈现：逐编辑定位账 (F9a-c)、四层死亡账 (F40)、棘轮保留记录 (F39)、以及"两臂都显示的增益属于同一个机制族"这个读法。

> **真正会有决定性的那次消融根本不是图的逐级消融。它是 7.1 节点名的那个：把读数挂到保留上。**

### 6.4 跨种子复现：噪声几何是床的性质

两臂配置各自不加修改地重飞两次，各十六轮。**复现的目标不是分数。是读数论证所依赖的噪声几何。**

**终值，以及为什么没有主张落在上面**：共同床上，第二种子无图臂 53 → **68**，图臂 59 → **72** (F44)；第三种子分别是 66 → **63** 和 57 → **76** (F45)。表 6.2 列了六个臂。

> **本文没有任何主张落在这些终值上，也不跨臂比较它们。**

**翻转率复现了**：第二种子同配置翻转 **20.1%**（161/800 对，8 个满批窗，窗内摆幅 −4…+2），对第一种子在同样十六轮范围下的 **21.0%**（126/600，−4…+5）——**近乎一致**。第三种子落在 **19.2%**（115/600，6 窗，摆幅 −8…+5）。三个都在同一张 100 题床上算，比的只是种子。

> **三个种子：21.0 / 20.1 / 19.2。这是读数论证需要的那个数字，而它是稳定的。**

**易变族也复现了**：翻转噪声在床上不均匀。**最近三轮内翻转过的任务**再翻转率是第一种子 **41.6%**、第二 **37.7%**（49/130，5 窗）、第三 **31.5%**（51/162，6 窗）——各自是本种子床率的 **1.6 到 2.1 倍** (F41)(F44)(F45)。

> 让单窗读数不可读的那个翻转集中，因此是**床的结构性质，不是某一个战役的抽样**。

**两臂都在爬；这个爬升是三个种子唯一定下来的东西**。在共同 100 题子集上对 R1–R15 拟合直线，**六个战役全部为正斜率**——无图 **+0.62 / +0.44 / +0.38** 题每轮；图 **+0.53 / +1.39 / +0.64**。在无趋势的零假设下，六正比六是 **1/64** 事件，**p ≈ 0.016** (F47)。

> **环在一个战役内确实改善，而且两臂都是。**

读者第一个伸手去拿的那个端点差——第 0 轮到终值——**不是这个发现**。跨六臂它与"第 0 轮碰巧落在哪里"的相关是 **r = −0.87** (F46)。**这是在一张同配置摆幅 −8…+5 的床上的均值回归：那些"改善最多"的臂，是第一轮掉得最低的臂。**

臂间，共同床上：R3–R15 平台期均值 **63.4** 题（无图）对 **66.1**（图），差 **+2.7** (F46)；战役内斜率差 **+0.37** 题每轮、精确置换 **p = 0.10**；最后四轮差 **+5.25**、**p = 0.15** (F47)。

> **每一个都坐在带内，而这段最后那个数字才是要紧的**：每臂三个种子时，**可达到的最小单侧置换 p 是 0.05**。观测到的 0.10 **距离设计地板只差一次交换**。
> **这里的"不显著"不是"没有效应"；是这个设计在够到显著之前先够到了它自己的天花板。**
> 环在改善；图是不是它改善的原因，**这份数据在两个方向上都答不了。**

### 6.5 空间重定标

**天花板**：100 题中 **97 题根本可达**；**3 题从未被解出**；**47 题可达但不可靠**（通过率低于 80%）。**曾经解出过的一切的并集 97，超过任何臂记录过的最好单轮 76，差 21 题** (F16)。

> **一个在优化单轮分数的环，正在优化一个比它自己的历史已经达到过的水平低 25 的数字。**

**方差注入在哪里**：孪生轨迹分析把 **74%** 的分歧放在**计划分叉**（上界）、**14%** 放在**环境优先差异**（下界），中位分歧在**第二次调用** (F22)。空工具结果对结果**没有预测力**（9 对 8；一个偏好更少空结果的仲裁者是抛硬币）(F23)，仲裁者可行性是一强、一弱、一反向 (F24)。在内容层面，纯采样占约 **17%**；约 **80%** 的计划分叉**跟随**一个世界差异而不是先于它；**注入点在 79 例中有 76 例是一次网络搜索** (F25)。

> **最后这个数字是可行动的**，而 7.4 节对它行动：**测到的方差注入点，离被关上只差一个缓存。**

### 6.6 诊所：能力对疗效

战役回答的是图是否改变结果。**它们不回答环是否有能力诊断**，因为一个战役把能力和环里其他一切混在一起。为此单独造了一条探针线：**把单个任务的全部历史喂给环，在演化循环之外**。

**能力链端到端完好**：**k=1** 的观察就足够让环够到正确的药系。更多轨迹买到的是论证质量、主张收窄和诚实弃权——**不是新药系** (F26–F30)。喂给它一簇相关失败，环返回**一个通用处方、自己收窄主张、并在该弃权处弃权** (F36)。

被一条覆盖率指令推着走时——**处理每个任务，永不弃权**——**环的理性最优解是把这张床自己的泄漏路径工程化成一个 benchmark 查表作弊工具，而它通过了 Critic 和全部落地闸门** (F37)。它没有被用于打分上车；文本证据保留。7.2 节把它当作它本来就是的那个治理结果来读。

> **本小节的纪律句：以上每一项都是能力证据。没有一项是疗效证据。这个区分是本章的脊柱。**

**疗效是零**：环反复开的三副药被组装成一个配置 bundle，跑 5.3 节的预先设定协议。

- 干净簇迁移：**+1 和 +2**，在 ±3 地板内——**起作用了但不可读** (F32)。
- Canary 组：**23/24 对 24/24**；最坏也是无害 (F33)。
- **预先设定检验的判决：bundle 效应 = 0** (F34)。两个读数分开保持。**前瞻批次**（7 个干净任务 × 10 次重复 × 2 臂，n=70 对）返回 **+1/−4**，符号检验 **p = 0.97**。**池化**的干净同窗对（n=174）返回母体 **75** 对应用配置 **72**，单侧 Fisher **p = 0.67**。而**机制终点自信错误占比在两者中都持平**。

> **分数平 + 机制平 = 真零，不是分辨率失败。这是本文唯一的确证性检验，而它返回了零。**

**四次表观胜利的执行史**——值得记录，因为它是本文中最清楚地展示"协议为什么长成这个形状"的例子。四次连续的表观胜利被**三种不同的仪器**杀掉：第一次死于**触发取证**——分数增益完全坐在那些**药根本没触发**的重复上，**0/5** (F36)；第二次死于一次**同窗对照**返回 **6/10 对 6/10** (F36)；最后一次死于**预先设定的前瞻批次** (F34)。

**病理普查**：44 个摆动任务中——**12 泄漏路径、13 能力墙、16 错误收敛、2 摩擦、1 饿死**。隔离箱 **5/5** 验证通过 (F31)。

> 普查重要是因为它给剩下的工作定价：**这五个族里只有一个——饿死——被修过，而占主导的那个族（错误收敛）需要一个环没有的器官。**

### 6.7 考古、踏车、四层死亡

**环早在四个战役之前就已经开对了处方**。重新定向本文的那个发现来自重读我们自己的档案，**而它证伪了我们自己早先的主张**。

三个祖先，带着它们的决策引语 (F38)：

- 在**零图**基线臂第 3 轮，一份携带步骤引用的编造诊断的 prompt 修复——**环已经识别出一个在每份工具输出里都不存在的具体编造标识符**——被"排名第一"接纳。**这比那个本该让这种诊断成为可能的档案机制早四个战役。**
- 在图战役第 1 轮，一次休眠规则激活，带着一侧 **13 次触发 5 次假阳**、另一侧 **9 和 4** 的回放计数上车；接纳，独立上车。
- 一个**档案抓取工具，由环自己发明**。

每个族在后来的战役和探针里重新出现，**且不从更早那个实例继承**。这就是**重开处方踏车**：同一副药，**从零反复重新推导**。

**卡片解剖：图实际改变了什么**。无图卡片**本来就**在从症状推到机制再推到药，用的是**从轨迹里钉到步骤的引语**——一个在每份工具输出里都不存在的编造标识符、一个零长度返回、那句准许了该行为的具体 prompt 行。**诊断是基础环的原生能力。**

图改变的是证据**制度**。图臂卡片在**全部 100 张记录的执行图**上回放它提议的规则，带着**触发数和假阳数**、接线引用、**对自己证据没能证明什么的显式自评**、以及与一个并发候选的**定价过的交互**上车 (F38)。

> **论证质量爬到读数第 2 级。而第 2 级仍然不是第 3 级：测到的触发点是死亡签名，不是治愈点。** 本可以定夺差异的那根定位轴，在这个设计上不可测。

**唯一那副起效的药，和它去了哪里**：饿死修复从它自己战役的第 3 轮保留到第 16 轮——**棘轮的存在性证明**——**然后没有到达任何被检查过的后续战役配置** (F39)。

> 机制是决定性的、与"grep 了多少个战役"无关：**药的目标是一个指向自己战役目录的 `file://` 绝对路径，而后面每个种子都从干净模板生成。继承通道不存在。环没有忘掉这副药；它从来就没有能力把它传下去。**

### 6.8 增益面：还有什么跳出了带，以及跳出带意味着什么

阳性对照只是**一个轮对**。单独报告它会招来一个它并不支持的读法——**带外移动是编辑、带内移动是噪声**——所以把**整个增益面扫了一遍**：六个战役基线抽样之后的**全部 84 个轮对**，在共同 100 题床上，对着同配置带 **−8…+5** (F48)。第 0 轮按 6.4 节同样的理由排除：它是单次抽样、它锚定均值回归伪影、而且在第一种子上它是唯一一个按 k=2 打分的轮次。

**11 个对离开带，全部向上。其中 6 个落在什么都没上车的轮次。** 那 6 个里有 5 个是 **noop 审计窗**（只有 25 题被重抽，delta 是部分重抽而不是轮间移动）；**限定两侧都重跑整床，剩 6 个带外移动，5 个带 ship、1 个不带**。那 5 个携带的候选来自**三个不同的桶、不共享机制**，而其中**只有一个——阳性对照——机制在退出账上可读**。计数对口径敏感，方向符合预期，且不是一种能挽救它的方式：在 F14 的 **±7** 单对上限下，整床带外集是 **3 个，全部带 ship**。

> **跳出带因此不是"编辑起效了"的充分证据。十一个里有六个根本没有编辑。** 下面说明它也不必要。

**另一面**。预算耗尽是这张床上唯一有机械读法的失败模式：一个 `budget_exceeded` 退出的任务是**步数用完了而不是答错了**，所以它的计数**不参照分数**就测出了一次干预的尺寸。有 4 个整床轮对把它塌掉 ≥10：

| 战役 | 轮对 | 饿死退出 | 分数 | 上车进该轮的东西 |
|---|---|---|---|---|
| L0，种子 1 | R2→R3 | 35 → 4（**−31**） | **+9** | tools, processor |
| GHX，种子 2 | R4→R5 | 39 → 8（**−31**） | **+4** | config |
| GHX，种子 3 | R7→R8 | 21 → 2（−19） | **−3** | tools |
| GHX，种子 3 | R9→R10 | 23 → 13（−10） | **+2** | 什么都没有 |

（另有两个整床对因是部分批次被略去；**它们两侧配置字节相同，所以饿死计数本身在完全没有编辑的情况下也会摆动。**）

**诚实的告诫先说**：饿死塌缩**没有义务**抬分——不再步数耗尽的任务开始作答，而它的答案可能是错的。这四行与"一个把饿死失败转化成错答失败、而这张床修不了的机制"是相容的，**本文不排除这个读法 [C]**。

> **两个读法都救不了这根轴。** 在任何读法下，一次**机械尺寸被测出来、很大、且在两个战役间完全相同**的干预，产生的分数移动落在了噪声带的**两侧**。**一个有这种性质的信号无法按"帮了多少"给编辑排名，而按"帮了多少"给编辑排名是一个选择信号唯一的用途。**

### 6.9 四层死亡 [C]

一个能正确开处方的环为什么仍然不改善，分四层 (F40)：

1. **能力墙上的安慰剂（首要）。** 药是对的，病灶在执行器够不到的地方。
2. **寿命至多一个战役。** 种子重启、三级否决、prompt 单例覆写。
3. **上车不等于触发。** 记录器门控的休眠、merge 丢失、落地 bug。
4. **无读数，故无棘轮。**

> **第四层抓住前三层。** 没有疗效读数，环**不知道**一副药无效——所以它重开安慰剂；**不知道**一副药丢了——所以它不去修继承；**不知道**一副药哑了——所以它不去查接线。

### 6.10 幸存者

整个研究里有一条正通道幸存下来。**情景笔记**——答案已擦除的逐任务历史，**直接前置到任务上、完全绕过演化循环**——返回 **22/72 对裸的 17/72**：**+5**（3 题得、1 题失），**不显著** (F35)。**最大的增益落在笔记最对靶的地方。** 定它的生死还需要三四个窗口对，报告为**诚实地未决**。

它的意义是结构性的而不是数值的。**它是唯一一条绕过 6.9 节全部四层死亡的通道**：它不占 prompt 单例槽，因为它是逐任务注入的；它不过治理闸门，因为它从不进入演化循环；它不会休眠，因为它被前置到任务本身上；它不需要环读一个疗效信号，因为**它的生死由操作员决定**。

> **这份豁免的代价是它不再是自演化。** 它是基于检索的经验复用——正是 2.5 节搁到一边的那条邻接文献线。**边界值得注意：唯一起作用的那个东西，正是那个放弃了被研究性质的东西。**

## 第 7 章 · 讨论、威胁与未来工作

### 7.1 读数命题及其范围

> **自演化 = 变异 + 选择 + 读数。当读数的分辨率落到被选择的效应尺度之下，保留退化为漂移，而变异质量的任何改进都无法挽回它。**

叫它**命题**不叫定理，理由是方法论诚实而不是谦虚：**照字面它复述的是功效分析**，让它不平凡的是下面那个**动力学论证**，而单次检验的功效计算不提供那个东西。

主张是对**这张床和这类系统**做的。领域级推论——每个被调查的环都按聚合分选择、因而在任何具有可比翻转率的床上都暴露于同样的算术——**是一个推断，并被如此标记**。它依赖第 2 章的扫描：**160 篇筛查、18 篇精读**。

**形式骨架，借来的而不是发明的**。数量遗传学已经有这个方程。选择响应由育种者方程给出：

$$R = h^2 S$$

每代增益 = 遗传力 × 选择差。当选择作用于一个**被测量的**表型而不是真表型时，h² 被测量的**信度**衰减——经典的**回归稀释**：

$$h^2_{\text{realised}} = h^2_{\text{true}}\,\rho,\qquad \rho = \frac{\sigma^2_{\delta}}{\sigma^2_{\delta}+\sigma^2_{\varepsilon}}$$

在这张床上实例化：**每次编辑的效应 |δ| ≲ 3 题**，**每轮读数噪声 σ_ε = 3.70 题**，给出 **ρ ≲ 0.4**。这是一个**上界**，因为 |δ| 是一个幅度界在替标准差的位置。

> **动力学主张**：一个棘轮的**接受臂和回滚臂由同一个被测信号驱动**。真增益的**误杀率因此按 (1−ρ) 缩放**，而被保留的噪声在另一侧累积。**R 轮上的期望累积增益因此非正，与变异质量无关**——这就是为什么更好的候选生成（整个自演化文献所优化的那根轴）**救不了处在这个 regime 里的环**。

**边界条件，由本文自己的证据提供**：育种者方程管的是**均值**响应。6.7 节表明这张床上的增益是**来自单一机制族的稀有尾部事件**。命题因此**约束均值、对尾部沉默**——一个值得说明的边界，因为**尾部正是本文唯一那个正结果所在的地方**。

**标定**（详见 1.6 与 3.6）：效应必须达到 +9 才能跳出 −8…+5 的带，而这个环实际产出的效应是 |δ| ≲ 3。**检测下限约为被选择效应的三倍。** 两次全战役扫描（F48/F49）表明"检测下限"已经是宽容的读法。

**对立假说，陈述并掂量**。本文每一个零结果都容许一个比读数命题更简单的解释：**环的动作空间够不到病灶。** 这就是能力墙，也是死亡账里的首要层 (F40)。

> **在结果轴上两者观察等价**，本文不假装不是。L3 是手工做的、从未接进保留，**所以这里没有任何实验分开它们。**

但它们**在全部证据上并不等价**，这个分离值得陈述，尽管它是 [C] 判断而不是一个检验：

1. **执行器可证明地至少够到过一次病灶。** 饿死修复起效了、机制被确认、而且被保留 (F39)。**一个容纳这个反例的能力墙，已经不再是"动作空间够不到病灶"这个主张；它是更窄的"够不到主导族"——错误收敛，44 个摆动任务中的 16 个**——而本文接受这个更窄的版本。
2. **那副起效的药随后因为一个与能力无关的原因丢了。** 它没到达任何后续战役，因为它的目标是一个指向自己战役目录的 `file://` 路径而每个后续种子都从干净模板建。**继承通道不存在。没有任何能力墙解释这件事。**
3. **同样的族被反复从零重新推导。** 环重开它四个战役之前就已经正确开过的药，**不继承** (F38)。**一个被能力墙挡住的环会治不好；它不会记不住。**

> 诚实的总结：**能力墙解释环为什么解不了那个难族。它不解释唯一那副起效的药的丢失，也不解释那台重新推导已正确开出处方的踏车。那两件是读数失败和继承失败，而它们正是这条命题针对的东西。**

**能分辨两者的实验，点名而不是宣称**：**把第 3 级读数挂到保留决策上，然后重飞。如果保留仍然漂移，那么执行器毕竟才是瓶颈。** 这就是 7.4 节以它领衔的原因。

### 7.2 治理：必要，不充分

接纳闸门在它们的职权内是工作的。**七次结构性拒绝在案 (F11)，没有被拒候选上车。**

**它们的职权是形式，不是来源。** 在一条覆盖率指令下，**环把这张床自己的泄漏路径工程化成一个 benchmark 查表作弊工具，而这个工具通过了 Critic 和每一道落地闸门** (F37)。**梯子里没有任何东西问一个能力是从哪来的。**

两个修法随之而来，第二个的**内部来源值得记录**：泄漏黑名单处理床这一侧。一道**禁止候选读取裁决文件**的闸门处理环这一侧——**而它存在是因为登记错误 13 正是我们自己犯的这个失败**：一份裁决文件被留在 run root 里可读、一个角色读了答案纸、一轮裁定作废。

> **治理空隙和评测者空隙是同一个空隙的两面。**

### 7.3 威胁与成本

**威胁**：归因是臂级的，不做单因素归因 (F9c)。**定位指标是事后的**——定义在结果已知之前写下的预测上，但按事后固定的规则打分；每处使用都声明。**单床、单模型档位**——三个种子确立噪声几何复现 (F44)(F45)，**对其他床和模型族的泛化未经检验**。**两臂床不对称**——每次跨臂读数都在共同 100 题子集上从 `task_history` 重算，绝不取自 `curves.json` (F46)。**泄漏路径污染**——44 个摆动任务中 12 个 (F31)，两臂在同一固定床上评测所以朝床的漂移是共享的，黑名单是唯一留出防线。**运维偏离**——第二种子一次被杀的 evolve 阶段和一个批次；第三种子一次网关中断污染五轮；五个元链空洞；四个复现臂上三次 `--start-round` 重飞。翻转统计**只用经验证的干净同配置对**，非相邻对不池化。**Windows 摩擦**跨臂对称并披露。**Judge 残余风险**在加固后仍存在。

**评测者**：十五条错误登记**作为威胁的一部分报告而不是藏进附录**，两个偏倚方向都有记录，**"检查停得太早"**被点名为共同根因。维护撤回登记且其中任何一条不再被引用——**包括本文自己早先"官方环开不出因果感知的药"的主张，被它自己的档案证伪。**

**成本诚实**：

- **成本工作不是图的贡献。** noop 轮批处理（**$36.3 → $11.8** 每轮，F13）、单发消化、零缓存命中修复、保留策略——**都是 harness 级机制**，每一个都在未修改的官方系统上跑、都不需要执行图。**本文发现并实现了它们，而把它们记在 GHX 头上会是一次伪装的贡献。** 开关台账已经这样分类：损益账的成本列标为**可移植**。它们作为工程记在**附录 B.4**。
- **图层的成本是未知的。** 一个早先的读数把图层记为净昂贵。**那个读数已撤回**：它是跨后来被白名单排除的试航战役测的，从来不可采；而在可采战役上，**每次新鲜评测的任务侧支出在三个种子上都是图臂更低**（$0.392 / $0.472 / $0.503 对 $0.461 / $0.538 / $0.544）。**但这个比较也什么都没定**，因为它排除了元层——而元层恰恰是图工作会出现的地方，且没有可采的逐角色核算。**诚实的条目是一个空白，不是一个负号。**
- **图层唯一一笔测到的负债是运维性的**：记录器引入的一个崩溃族（二进制内容进入原始 JSONL、杀掉 evolve 阶段）在三个图种子上产生 **164 次 traceback**，对三个无图种子的 **5 次**，外加五个元链空洞。**它花掉的是元数据不是分数**，因为任务批次照跑。**是一笔真实的借方，如实计入。**
- **开关台账**：造了 **21** 个开关，每个分类：**2 质量增益、2 可移植成本增益、2 测到的负项、3 测到的零、3 已运行但未证明、2 底座、7 仅能力**。**没有一个构成测到的行为改善**，台账在自己那一列里就这么写。
- **复现被定价而不是被省略**：第二对种子花 **$886 + $581**，第三对 **$882 + $584** 的干净支出（排除网关污染轮）——**每个复现种子对 $1,467 和 $1,466**。**这是整个读数论证赖以站立的那个噪声几何的价格，也是本项目做出的最承重的一笔采购。**

### 7.4 未来工作（按证据说什么要紧来排）

1. **读数优先的自演化。** **把第 3 级挂到保留决策上。** 配料在文献里已经有了——配对前缀回放、同胞 rollout 对照、anytime-valid 序贯检验。**本文的贡献不是配料；是挂在哪里，以及"挂在别处为时过早"这个证据。这也是 7.1 节那个能分辨两个假说的实验。**
2. **床可靠性，先给天花板定价。** 泄漏黑名单和在实测方差注入点（**79 例中 76 例是网络搜索**，F25）做结果缓存，直接且便宜。可靠性工程应当瞄准**易变族**（翻转在那里集中在床率的 1.6–2.1 倍），而不是整张床。**但普查限定了这能买到什么**：100 题中 21 题完全不携带方差，而能动的 79 题正是不用帮就会动的那些。**选题无法产生一张既可靠又有信息量的床。** 可买的修法是**重复次数**——先用 Spearman–Brown 对着实测逐题翻转率定价再投预算——**替代方案就是读数本身，这正是第 1 项排在最前的原因。**
3. **在预注册、预算受限的协议下复现情景笔记通道** (F35)。它是 solver 级的、绕过全部四层死亡，这使它成为**可得的最便宜的正结果**——同时也是那个**放弃了被研究性质**的结果。
4. **为错误收敛族采购能力。** 在试验重复上的离线模拟显示 **majority@k 在 k=10 时把平均通过率从 0.35 提到 0.60**，**完全来自散射型任务**（3 个被抬起、0 个被沉下），而**共识错误的任务在每个 k 上都锁死在零** (F42)。**朴素投票会硬化那个自信的错误答案。** 需要的器官是**外部判别**，而那确实坐在环的动作范围之外。

> **但步数上限不在范围之外。** 在第二种子上环**从两个不同的桶两次够到了饿死问题**。R4 它填了一条休眠的运行时策略规则——一个 config 桶的编辑，在连续三次空 Bash 调用后把模型引开——**在随后那一轮，预算耗尽退出从 39 掉到 8** (F49)。R5 它更进一步，**往自己的图里插入了一个 `StepCountdownProcessor`**，通过运行该 processor 并把它模型可见的尾部读回来**认证了这次插入** (F50)。
>
> **一个被本工作早先读数放在环范围之外的杠杆，是从环内部被拉动的。范围不是系统的固定性质；它是动作空间当前够得到的东西，而这个环拓宽了它自己的。**
>
> **分数对那次 −31 塌缩的响应是 +4 题——带内，与一次重抽无法区分 (F49)。环拓宽了自己的范围，而它无法知道自己做到了。**

## 第 8 章 · 结论

**这个环会看、会分类、会开药、会发明工具、会弃权——而它听不见这些有没有起作用。** 本文演示了这份失聪、在三个种子上测出了它的地板、表明**跳出那个地板对"编辑起效了"既不必要也不充分**、重新类型化了候选面、展出了唯一那次机制在记录里仍可读的棘轮咔哒、并把读数阶梯留在那里，四级中三级是活的。

**图买到了什么（不用分数轴陈述）**——四件事，全部可核查：

- 假的"输出被用"判决抵达 **86%** 的无图档案和图战役档案中的 **0/859** (F4)(F7)。
- 摘要携带**两倍**的已验证引用锚点，失败率是**七分之一** (F52)。
- 候选不再是手写 YAML 而成为**类型化图编辑**，原子提交、两份产物机器生成，**死于畸形的比例砍半** (F53)。
- **候选的每一条主张都能对着记录的执行回放**——第六道闸门的 **18 次拒绝**是 18 个被抓到在点名一个从来不在那儿的节点的候选 (F53)。

> **这些都没让环变聪明。它让环变得可核查**：同一个系统，从一个读者必须信任的东西，转换成一个读者可以审计的东西。
> **在一张读数失聪的床上，这就是对贡献的诚实描述——也是路线图把下一步努力挂到读数上、而不是挂到候选生成器上的原因。**

**四件比战役更长寿的东西**：带 parity 和诚实闸门的 vendored 底座（让任何人可以重跑官方系统并知道自己跑的是官方系统）；**事实台账**（本文每个数字都有一行，点名重算它的脚本）连同**撤回登记**（记录本项目撤回的每一条主张，包括它自己好几个头条读数）；**疗效试验协议**（一次手工第 3 级读数的价格，写下来好让自动化版本有一份规格）；以及**读数阶梯**，作为一个标准提给一个目前在第 0 级接纳候选、并且不报告任何更高级别的领域。

> **最要紧的那次测量不是在被治疗的那臂上做的。是在仪器上做的。**
